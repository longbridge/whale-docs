WhaleSDK 交付已經實現的客戶端交易 UI 與完整業務功能。Broker 將它整合到自己的 App 中，主要負責 SDK 整合、身份銜接、品牌配置和發布 —— 不需要重新實現交易功能。

它提供三種交付形態：

- **iOS** —— 面向券商 iOS 客戶端的原生交付形態
- **Android** —— 面向券商 Android 客戶端的原生交付形態
- **WebTrade** —— 面向 Web 頁面或 WebView 容器的交付形態

<Note>
本欄目建設中。現有的 iOS / Android / WebTrade 材料正在盤點納入；共享集成內容（身份銜接、品牌配置、生命週期、發布）只定義一次，平台頁只承載差異。
</Note>

## 責任邊界

WhaleSDK 的每個頁面都會區分：

- **由 WhaleSDK 完整提供** —— 交易 UI 與業務功能
- **Broker App 的責任** —— 整合 WhaleSDK、身份 / 會話銜接、原生權限、發布
