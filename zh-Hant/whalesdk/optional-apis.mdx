> 此文件列舉一些對特定 Broker 公開的 SDK 介面，這些介面在 SDK 的介面文件中沒有說明。
>
> 如：行為埋點資料回撥 目前 螞蟻 在使用。
>
>

## 行為埋點資料回撥

Android

```kotlin
LBWhaleApp.callback = object : LBWhaleAppCallback {
    //SDK 內部埋點事件轉發回撥
    //eventName：事件名；properties：事件屬性（org.json.JSONObject）
    override fun onLBWhaleAppAnalyticsEvent(eventName: String, properties: org.json.JSONObject) {}
}
```

iOS

```objective-c
#pragma mark - LBWhaleAppDelegate
/// 埋點事件觸發回撥
/// - **Parameters**:
///   - name: 事件名稱
///   - properties: 事件屬性
- (**void**)lbWhaleAppAnalyticsEventWithName:(NSString *)name properties:(NSDictionary *)properties;
```

- `$AppViewScreen` - 顯示介面

- `$AppPageLeave` - 退出介面

- `$AppClick` - 點選

- `whale_sdk_****` 如（whale_sdk_start、whale_sdk_start_success、whale_sdk_start_callback_run 等等）這些是 Broker App 呼叫 SDK 介面以及 SDK 回撥的埋點，這些應該在 Broker App 自己更好。

- 業務埋點，如（community_content_exposure、search_result_exposure、news_feed_exposure）有很多，都是業務資料暴光點選埋點，這些對你們沒用。
