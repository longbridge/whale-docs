---
title: Trading API 與 WhaleCore
description: 使用無 UI 資料 SDK 和 HTTP API 建構完全自研交易客戶端
---

Broker 如果希望完全自研客戶端圖形介面，可以組合使用 **WhaleCore** 和 **Trading API**。

- **WhaleCore** 是 WhaleSDK 的無 UI 底層資料 SDK，提供行情訂閱、WebSocket 連線、認證簽名和 token 續期。
- **Trading API** 是以單個 Customer 身分授權的 HTTP API，提供帳戶、資產和交易等業務能力。

iOS 和 Android 原生 WhaleCore 庫已可用，Web 客戶端的 WebAssembly 版本開發中。

<Note>
WhaleCore 不提供圖形介面，也不取代 Trading API。自研客戶端通常同時使用兩者。
</Note>

如果希望直接取得完整圖形介面，請使用 [WhaleSDK](/zh-Hant/whalesdk/overview)。
