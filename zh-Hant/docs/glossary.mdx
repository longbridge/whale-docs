---

Whale Docs 術語的唯一權威來源。產品文件連結到本頁，不重複定義這些術語。

## 產品

| 術語 | 定義 |
| --- | --- |
| **Whale** | Longport Whale SaaS 證券業務系統解決方案；本文件統一簡稱 Whale 。 |
| **Whale Docs** | Longport Whale 的統一文件門戶。它是門戶，不是 API 產品。 |
| **Whale SDK** | Whale 的客戶端 SDK 產品族總稱，包含圖形介面 SDK WhaleApp SDK 和無 UI 資料 SDK WhaleCore SDK。 |
| **WhaleApp SDK** | Whale SDK 中提供完整證券業務圖形介面的 SDK，包含 iOS、Android 與 WebTrade 三種形態。 |
| **WhaleCore SDK** | Whale SDK 中不含 UI 的資料 SDK。面向 iOS、Android、Web 三個平臺；iOS、Android 已可用，Web 的 WebAssembly 版本開發中。提供行情訂閱、WebSocket、認證簽名和 token 續期等基礎機制。 |
| **WebTrade** | WhaleApp SDK 中面向 Web 頁面、iframe 或 WebView 容器的圖形介面交付形態。 |
| **Broker API** | 供 Broker Server 以 Server-to-Server 方式呼叫的機構級 API，授權範圍可覆蓋該 Broker 下的資料與 SaaS 櫃檯能力。 |
| **Trading API** | 供 Broker App 使用的 Customer 級 HTTP API，通常與 WhaleCore SDK 配合，用於完全自行實現證券功能 UI。 |
| **OpenAPI** | 面向 Broker 的 Customer 的開放能力。用於策略交易、量化分析和開發者工具，並透過 MCP 等 AI-native 方式讓 Customer 授權 AI 接入其帳戶、資產、行情和基本面資料。 |

## 參與方與角色

| 術語 | 定義 |
| --- | --- |
| **Broker** | 接入 Whale 的機構，負責自己的產品、Customer 服務及專案上線，也是 Broker API 的授權邊界。 |
| **Customer** | Broker 服務的終端客戶，是 WhaleApp SDK、WhaleCore SDK、Trading API 與 OpenAPI 的客戶級身份。 |
| **Broker Developer** | 代表 Broker 建設 Broker Server 整合或 Broker App 的開發人員。 |
| **Broker App Developer** | 代表 Broker 開發 iOS、Android、桌面或 Web Broker App 的開發人員。 |
| **Developer Customer** | 使用 OpenAPI 開發策略交易、量化分析、開發者工具或 AI 應用的 Broker Customer。 |

## 授權

| 術語 | 定義 |
| --- | --- |
| **Broker-scoped Authorization（機構級授權）** | Broker 機構級訪問許可權，可按獲批能力訪問該 Broker 範圍內的資料。 |
| **Customer-scoped Authorization（客戶級授權）** | 由單個客戶授予的訪問許可權，只覆蓋該客戶的私有資料和平臺公開資料。 |
