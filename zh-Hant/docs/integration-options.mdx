description: 按調用方與授權主體選擇正確的接入路徑

Longport Whale 提供一個嵌入式客戶端產品和三種 API。選哪個取決於**誰在調用**，以及**調用被授權訪問誰的資料**。

## 對比

| 產品 | 調用方 | 授權主體 | 私有資料範圍 | 形態 | 狀態 |
| --- | --- | --- | --- | --- | --- |
| [WhaleSDK](/zh-Hant/whalesdk/overview) | Broker App 開發團隊 | **Customer** | 單個客戶 | iOS / Android / WebTrade 圖形介面 | 可用 |
| [Broker API](/zh-Hant/broker-api/overview) | 券商後端服務 | **Broker** | 獲批的機構範圍 | Server-to-Server | 可用 |
| [WhaleCore + Trading API](/zh-Hant/trading-api/introduction) | Broker App | **Customer** | 單個客戶 | 資料 SDK + HTTP API | iOS / Android 可用；WebAssembly 開發中 |
| [OpenAPI ↗](https://open.longportapp.com) | Broker 的開發者 Customer、AI 應用 | **Customer** | 單個客戶 | Open API / SDK / MCP | 可用於策略交易、量化分析及 AI 接入 Customer 帳戶與市場資料 |

## 如何選擇

- **現成 UI vs 完全自研 UI** —— 使用 **WhaleSDK** 取得完整交易介面；完全自研客戶端介面時使用 **WhaleCore + Trading API**。WhaleCore 提供行情訂閱、WebSocket、認證簽名和 token 續期等無 UI 基礎機制。
- **機構授權 vs 客戶授權** —— 以券商機構身份運行的後端集成用 **Broker API**；以單個終端客戶身份運行的一律屬於 **Trading API** 或 **OpenAPI**。
- **券商開發者 vs 開發者客戶** —— 前者代表券商，後者是券商服務的客戶。即使兩者調用相似的行情或交易能力，也不共享授權模型。

<Note>
平台公開內容（行情、基本面、資訊）仍歸屬提供它的 API 產品 —— 「公開」不代表無需認證。
</Note>
