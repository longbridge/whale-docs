<AccordionGroup>
  <Accordion title="我應該對接哪個 API？">
    取決於誰在調用、訪問誰的資料。見[接入方式選擇](/zh-Hant/docs/integration-options)，一張表給出答案。
  </Accordion>
  <Accordion title="如何取得 Broker API 憑證？">
    機構級 `ACCESS_TOKEN` 由 Longport Whale 按券商簽發。見[鑑權](/zh-Hant/broker-api/get-started/authentication)。
  </Accordion>
  <Accordion title="有測試環境嗎？">
    有 —— `https://b-api.longbridge.xyz`。API Playground 預設使用測試環境，試調不會影響生產資料。
  </Accordion>
</AccordionGroup>
