Longport Whale 是面向券商的 SaaS 證券業務系統解決方案。Whale Docs 是它的統一文件門戶，覆蓋產品本身、櫃台操作、實施流程與三種 API 接入方式。

## 產品

<CardGroup cols={2}>
  <Card title="WhaleSDK" icon="smartphone" href="/zh-Hant/whalesdk/overview">
    將完整交易體驗嵌入自有客戶端 —— 提供 iOS、Android 與 WebTrade 三種形態的可直接集成 UI。
  </Card>
  <Card title="Broker API" icon="server" href="/zh-Hant/broker-api/overview">
    面向券商後端的機構級 Server-to-Server API。以券商機構為授權邊界，覆蓋機構資料與 SaaS 櫃台能力。
  </Card>
  <Card title="Trading API" icon="chart-candlestick" href="/zh-Hant/trading-api/introduction">
    結合無 UI 的 WhaleCore 與 Customer 級 HTTP API，建構完全自研的 Broker 客戶端。
  </Card>
  <Card title="OpenAPI" icon="plug" href="https://open.longportapp.com">
    供 Broker 的 Customer 開發策略交易、量化分析和 AI 應用，並透過 MCP 等 AI-native 方式接入帳戶資產、行情與基本面能力。
  </Card>
</CardGroup>

## 按角色進入

| 你是 | 首要任務 | 入口 |
| --- | --- | --- |
| 券商決策者 / 產品負責人 | 理解 Whale 能力、實施範圍和上線過程 | 本欄目（Docs） |
| 券商實施團隊 | 理解業務流程、準備資料、完成驗收 | 本欄目（Docs） |
| Broker App 開發團隊 | 將完整交易 UI 嵌入 Broker App 或 Web 容器 | [WhaleSDK](/zh-Hant/whalesdk/overview) |
| 券商後端開發者 | 以機構身份集成 SaaS 櫃台能力 | [Broker API](/zh-Hant/broker-api/overview) |
| 券商客戶端開發者 | 使用 WhaleCore 與 Trading API 完全自研交易 UI | [Trading API 與 WhaleCore](/zh-Hant/trading-api/introduction) |
| Broker 的開發者 Customer / AI 使用者 | 開發策略、量化分析，或授權 AI 接入自己的帳戶與市場資料 | [OpenAPI ↗](https://open.longportapp.com) |
