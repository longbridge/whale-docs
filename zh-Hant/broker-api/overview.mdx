title: Broker API

---

Broker API 是面向 Broker 的機構級 API，可用於 Server-to-Server 系統整合，也可為 Broker 自研管理後臺提供資料與 SaaS 櫃檯能力。它以 **Broker** 為授權主體，一份憑證覆蓋機構獲批範圍內的能力。

無論用於系統整合還是自研管理後臺，實際 API 請求都應由 Broker 控制的服務端發起。Access Key 等機構憑證不得存放在瀏覽器程式碼或 Broker App 中；自研管理後臺介面應透過 Broker Server 呼叫 Broker API。

## 一覽

| | |
| --- | --- |
| 呼叫方 | Broker Server、Broker 自研管理後臺的服務端 |
| 授權主體 | Broker（**機構級授權 / Broker-scoped Authorization**） |
| 私有資料範圍 | 獲批的機構範圍 |
| 形態 | HTTPS API；支援 Server-to-Server 整合與自研管理後臺 |

## 不適用於

- Broker App 使用 WhaleCore SDK 完全自行實現證券功能 UI —— 請使用 [WhaleCore SDK 與 Trading API](/zh-Hant/trading-api/introduction)
- 由 Developer Customer 構建第三方應用 —— 請使用 [OpenAPI ↗](https://open.longportapp.com)
- 嵌入移動端交易 UI —— 請使用 [WhaleApp SDK](/zh-Hant/whalesdk/mobile-integration)
