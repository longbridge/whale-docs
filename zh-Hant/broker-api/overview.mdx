Broker API 是供 Broker Server 以 Server-to-Server 方式呼叫的機構級 API。以 **Broker** 為授權主體，一份憑證覆蓋機構獲批範圍內的資料與 SaaS 櫃檯能力。

## 一覽

| | |
| --- | --- |
| 呼叫方 | Broker Server |
| 授權主體 | Broker（**機構級授權 / Broker-scoped Authorization**） |
| 私有資料範圍 | 獲批的機構範圍 |
| 形態 | Server-to-Server（HTTPS） |

## 不適用於

- Broker App 使用 WhaleCore SDK 完全自行實現證券功能 UI —— 請使用 [WhaleCore SDK 與 Trading API](/zh-Hant/trading-api/introduction)
- 由 Developer Customer 構建第三方應用 —— 請使用 [OpenAPI ↗](https://open.longportapp.com)
- 嵌入移動端交易 UI —— 請使用 [WhaleApp SDK](/zh-Hant/whalesdk/mobile-integration)
