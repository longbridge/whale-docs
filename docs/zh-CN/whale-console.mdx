Whale Console 是运营 Longport Whale 的后台控制台。其使用手册覆盖整个控制台的日常柜台业务、审核、配置和监控。

<Note>
访问需要 IP 白名单。Broker 完成 Onboarding 后，Whale 会为其开通白名单访问；Whale Console 本身也仅限白名单 IP 访问。
</Note>

## 访问前提 {/* before-you-can-access */}

- 完成 Broker Onboarding，参见 [Broker 上线](/zh-cn/docs/broker-onboarding)。
- 由 Whale 为你的机构开通 IP 白名单访问。
- 在白名单网络环境下访问控制台及其手册。

## 打开 Whale Console 手册 {/* open-the-manual */}

开通访问后，打开手册：

[打开 Whale Console 手册](https://docs.longportwhale.com/zh-cn/docs/)

如果链接无法打开，通常是你的 IP 尚未加入白名单。请联系项目团队确认 Onboarding 状态与白名单配置。
