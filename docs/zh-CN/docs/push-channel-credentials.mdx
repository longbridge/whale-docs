本文档是 Whale 托管推送方案的资料收集模板，用于确认 Broker App 在 UAT 与生产环境需要开通的 Android 厂商渠道和 iOS APNs 配置。

<Warning>
本页只定义需要收集的字段，不应直接填写并提交真实密钥。证书、密码、Client Secret 和服务账号密钥必须通过双方批准的秘密交付渠道传输，并记录环境、保管人、有效期和轮换方式。
</Warning>

## 填写规则 {/* completion-rules */}

1. 生产与 UAT 必须分别确认 App 标识和渠道配置。
2. 两个环境的 Android Package Name 相同时，只填写生产信息，UAT 填写“无”。
3. 不需要的推送渠道在“信息”列填写“无”，不要留空。
4. iOS 的 `.p12` 与 `.p8` 只需选择一种；未提供的凭证列删除。
5. 每份凭证都应注明有效期和负责轮换的 Broker 联系人。
