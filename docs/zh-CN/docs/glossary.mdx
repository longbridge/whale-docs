Whale Docs 术语的唯一权威来源。产品文档链接到本页，不重复定义这些术语。

## 产品

| 术语 | 定义 |
| --- | --- |
| **Whale** | Longport Whale SaaS 证券业务系统解决方案；本文档统一简称 Whale 。 |
| **Whale Docs** | Longport Whale 的统一文档门户。它是门户，不是 API 产品。 |
| **Whale SDK** | Whale 的客户端 SDK 产品族总称，包含图形界面 SDK WhaleApp SDK 和无 UI 数据 SDK WhaleCore SDK。 |
| **WhaleApp SDK** | Whale SDK 中提供完整证券业务图形界面的 SDK，包含 iOS、Android 与 WebTrade 三种形态。 |
| **WhaleCore SDK** | Whale SDK 中不含 UI 的数据 SDK。面向 iOS、Android、Web 三个平台；iOS、Android 已可用，Web 的 WebAssembly 版本开发中。提供行情订阅、WebSocket、认证签名和 token 续期等基础机制。 |
| **WebTrade** | WhaleApp SDK 中面向 Web 页面、iframe 或 WebView 容器的图形界面交付形态。 |
| **Broker API** | 面向 Broker 的机构级 API，支持 Server-to-Server 集成，也可为 Broker 自研管理后台提供数据与 SaaS 柜台能力；实际请求由 Broker 控制的服务端发起。 |
| **Trading API** | 供 Broker App 使用的 Customer 级 HTTP API，通常与 WhaleCore SDK 配合，用于完全自行实现证券功能 UI。 |
| **OpenAPI** | 面向 Broker 的 Customer 的开放能力。用于策略交易、量化分析和开发者工具，并通过 MCP 等 AI-native 方式让 Customer 授权 AI 接入其账户、资产、行情和基本面数据。 |

## 参与方与角色

| 术语 | 定义 |
| --- | --- |
| **Broker** | 接入 Whale 的机构，负责自己的产品、Customer 服务及项目上线，也是 Broker API 的授权边界。 |
| **Customer** | Broker 服务的终端客户，是 WhaleApp SDK、WhaleCore SDK、Trading API 与 OpenAPI 的客户级身份。 |
| **Broker Developer** | 代表 Broker 建设 Broker Server 集成或 Broker App 的开发人员。 |
| **Broker App Developer** | 代表 Broker 开发 iOS、Android、桌面或 Web Broker App 的开发人员。 |
| **Developer Customer** | 使用 OpenAPI 开发策略交易、量化分析、开发者工具或 AI 应用的 Broker Customer。 |

## 授权

| 术语 | 定义 |
| --- | --- |
| **Broker-scoped Authorization（机构级授权）** | Broker 机构级访问权限，可按获批能力访问该 Broker 范围内的数据。 |
| **Customer-scoped Authorization（客户级授权）** | 由单个客户授予的访问权限，只覆盖该客户的私有数据和平台公开数据。 |
