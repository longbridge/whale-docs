Whale Docs 术语的唯一权威来源。产品文档链接到本页，不重复定义这些术语。

## 产品

| 术语 | 定义 |
| --- | --- |
| **Whale** | Longport Whale SaaS 证券业务系统解决方案；本文档统一简称 Whale 。 |
| **Whale Docs** | Longport Whale 的统一文档门户。它是门户，不是 API 产品。 |
| **WhaleSDK** | Whale 的客户端 SDK 产品族总称，包含图形界面 SDK WhaleAppSDK 和无 UI 数据 SDK WhaleCoreSDK。 |
| **WhaleAppSDK** | WhaleSDK 中提供完整证券业务图形界面的 SDK，包含 iOS、Android 与 WebTrade 三种形态。 |
| **WhaleCoreSDK** | WhaleSDK 中不含 UI 的数据 SDK。面向 iOS、Android、Web 三个平台；iOS、Android 已可用，Web 的 WebAssembly 版本开发中。提供行情订阅、WebSocket、认证签名和 token 续期等基础机制。 |
| **WebTrade** | WhaleAppSDK 中面向 Web 页面、iframe 或 WebView 容器的图形界面交付形态。 |
| **BrokerAPI** | 面向 Broker 的机构级 API，支持 Server-to-Server 集成，也可为 Broker 自研管理后台提供数据与 SaaS 柜台能力；实际请求由 Broker 控制的服务端发起。 |
| **TradingAPI** | 供 Broker App 使用的 Customer 级 HTTP API，通常与 WhaleCoreSDK 配合，用于完全自行实现证券功能 UI。 |
| **OpenAPI** | 面向 Broker 的 Customer 的开放能力。用于策略交易、量化分析和开发者工具，并通过 MCP 等 AI-native 方式让 Customer 授权 AI 接入其账户、资产、行情和基本面数据。 |

## 参与方与角色

| 术语 | 定义 |
| --- | --- |
| **Broker** | 接入 Whale 的机构，负责自己的产品、Customer 服务及项目上线，也是 BrokerAPI 的授权边界。 |
| **Customer** | Broker 服务的终端客户，是 WhaleAppSDK、WhaleCoreSDK、TradingAPI 与 OpenAPI 的客户级身份。 |
| **Broker Developer** | 代表 Broker 建设 Broker Server 集成或 Broker App 的开发人员。 |
| **Broker App Developer** | 代表 Broker 开发 iOS、Android、桌面或 Web Broker App 的开发人员。 |
| **Developer Customer** | 使用 OpenAPI 开发策略交易、量化分析、开发者工具或 AI 应用的 Broker Customer。 |

## 授权

| 术语 | 定义 |
| --- | --- |
| **Broker-scoped Authorization（机构级授权）** | Broker 机构级访问权限，可按获批能力访问该 Broker 范围内的数据。 |
| **Customer-scoped Authorization（客户级授权）** | 由单个客户授予的访问权限，只覆盖该客户的私有数据和平台公开数据。 |

## 标的标识

同一个标的在 Whale 中有两种标识格式：`counter_id` 用于系统内部，`symbol` 用于 OpenAPI。`counter_id` 可单向转换为 `symbol`，反之则不行。

### counter_id

`counter_id` 是 Longport Whale 系统内部通用的标的标识，几乎所有内部 API 与场景中出现的 `counter_id` 含义都一致。格式为 `{TYPE}/{MARKET}/{CODE}`。

| 段 | 含义 | 说明 |
| --- | --- | --- |
| `TYPE` | 标的类型 | 见下表；解析时统一转为大写 |
| `MARKET` | 市场 | 如 `US`、`HK`、`SH`、`SZ`、`SG`、`JP`；解析时统一转为大写 |
| `CODE` | 标的代码 | 大小写敏感，保留原始写法 |

`TYPE` 取值：

| TYPE | 含义 |
| --- | --- |
| `ST` | 股票 |
| `ETF` | 场内基金 |
| `UT` | 场外基金（货币型除外） |
| `MMF` | 货币基金 |
| `WT` | 轮证 |
| `IX` | 市场指数 |
| `BK` | 板块 / 自定义指数 |
| `OP` | 期权（仅美股） |
| `DLC` | 新加坡每日杠杆证书 |
| `VA` | 虚拟货币 |
| `PE` | 私募基金 |
| `LB` | 未上市公司 |
| `TN` | 私有标的（无行情） |
| `DP` | 财富衍生产品 |

示例：

- `ST/US/NVDA` — 美股英伟达
- `ST/HK/700` — 港股腾讯
- `ST/SZ/11245`、`ST/SH/076251` — A 股（`SH`、`SZ` 归属地区为 `CN`）
- `ST/SG/D05` — 新加坡股
- `OP/US/BILI/220304C30500` — 美股期权（`CODE` 段可包含额外的 `/`）

注意：

- `CODE` 大小写敏感；`TYPE` 与 `MARKET` 会在解析时转为大写。
- 港股数字代码在展示时补零到 5 位（如 `00700`），但 `counter_id` 字符串本身使用原始代码（如 `700`）。

### symbol

`symbol` 一般用于 OpenAPI，格式为 `{CODE}.{MARKET}`，例如 `TSLA.US`、`700.HK`。

<Note>
转换是单向的：将 `counter_id` 去掉 `TYPE` 段、重排为 `{CODE}.{MARKET}` 即可得到 `symbol`（如 `ST/HK/700` → `700.HK`）。反过来不行——`symbol` 不含 `TYPE`，无法直接还原出 `counter_id`。
</Note>
