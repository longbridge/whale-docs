## 1. 准备凭证 {/* 1-prepare-credentials */}

你需要为券商机构签发的一项凭证：

| 凭证 | 请求头 | 说明 |
| --- | --- | --- |
| `ACCESS_TOKEN` | `Authorization: Bearer <token>` | 由 Longport Whale 签发的机构级访问令牌 |

## 2. 发起第一个请求 {/* 2-send-your-first-request */}

以下示例查询 `account_cash_balances` 数据集（`GET /v1/datasets/account_cash_balances`）：

```bash cURL
curl --get \
  --url https://b-api.longbridge.xyz/v1/datasets/account_cash_balances \
  --header "Authorization: Bearer ${ACCESS_TOKEN}" \
  --data-urlencode 'filters={}' \
  --data-urlencode 'page=1' \
  --data-urlencode 'page_size=20'
```

```python Python
import requests

ACCESS_TOKEN = "${access_token}"

host = "https://b-api.longbridge.xyz"  # 生产环境：https://b-api.lbkrs.com
uri = "/v1/datasets/account_cash_balances"

resp = requests.get(
    url=host + uri,
    headers={"Authorization": f"Bearer {ACCESS_TOKEN}"},
    params={"filters": "{}", "page": 1, "page_size": 20},
)
print(resp.json())
```

<Tip>
切换测试 / 生产环境只需修改 `host` —— 测试环境 `https://b-api.longbridge.xyz` 不会影响真实数据。
</Tip>
