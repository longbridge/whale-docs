---
title: 透传请求头
description: 由网关原样转发至后端服务的请求头
---

以下请求头由网关原样透传给后端服务，不做任何修改。通过设置这些请求头可控制响应语言、客户端平台及版本相关的业务行为。

## accept-language {/* accept-language */}

指定响应内容的偏好语言。缺省时回退到系统默认语言。

| 取值 | 语言 |
| --- | --- |
| `zh-CN` | 简体中文 |
| `zh-HK` | 繁体中文 |
| `en` | 英文 |

## x-platform {/* x-platform */}

标识请求来源的客户端平台。

| 取值 | 平台 |
| --- | --- |
| `ios` | iOS |
| `android` | Android |
| `web` | Web |

## x-app-version {/* x-app-version */}

标识客户端应用版本，例如 `3.28.0`。用于版本相关的业务逻辑及会话元数据。

## x-timestamp {/* x-timestamp */}

携带请求时间戳。
