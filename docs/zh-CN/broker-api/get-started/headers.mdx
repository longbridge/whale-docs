---
title: 请求头
description: 由网关原样转发至后端服务的请求头
---

以下请求头由网关原样透传给后端服务，不做任何修改。

## Content-Type {/* content-type */}

指定请求体格式。请求体为 JSON 时使用 `application/json`。

## Accept-Language {/* accept-language */}

指定响应内容的偏好语言。缺省时回退到系统默认语言。

| 取值 | 语言 |
| --- | --- |
| `en` | 英文 |
| `zh-CN` | 简体中文 |
| `zh-HK` | 繁体中文 |

## X-Timestamp {/* x-timestamp */}

携带请求时间戳。
