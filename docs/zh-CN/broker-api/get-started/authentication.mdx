---
title: 鉴权
description: 基于 ACCESS_TOKEN 的请求鉴权
---

BrokerAPI 使用 `ACCESS_TOKEN` 对每个请求进行鉴权：将券商机构的 `ACCESS_TOKEN` 以 `Bearer` 方案放入 `Authorization` 请求头即可。

## 必需请求头 {/* required-headers */}

| 请求头 | 取值 | 示例 |
| --- | --- | --- |
| `Authorization` | `Bearer ACCESS_TOKEN` | `Bearer ${access_token}` |
| `Content-Type` | 内容类型 | `application/json; charset=utf-8` |

## 请求示例 {/* example-request */}

```bash cURL
curl --request POST \
  --url https://b-api.longbridge.xyz/v1/datasets/account_cash_balances \
  --header "Authorization: Bearer ${ACCESS_TOKEN}" \
  --header "Content-Type: application/json; charset=utf-8" \
  --data '{"filters": {}, "page": 1, "page_size": 20}'
```

## 获取凭证 {/* obtaining-credentials */}

`ACCESS_TOKEN` 为机构级凭证（**机构级授权 / Broker-scoped Authorization** —— 覆盖机构获批的数据范围），由机构管理员在后台自助创建：

1. 进入 **全局设置 → 身份管理 → API Token**。
2. 点击右上角 **新建 Token**，在 **创建 Access Token** 弹窗中填写：
   - **名称**：便于识别用途（例如：对账服务、行情同步）。2–30 个字符；名称同时作为 service 账号名，**租户内唯一，且删除后不可复用**。
   - **过期时间**：按需选择（如 `1 天`）。
3. 点击 **创建**。系统会**一次性**显示完整 `ACCESS_TOKEN`，请立即复制并妥善保存；**弹窗关闭后无法再次查看，丢失后只能重新创建**。

创建后可在 API Token 列表查看密钥名称、密钥前缀、状态、过期时间、最近使用时间 / IP、创建时间，并对每个 Token 执行编辑、重置 Token、启用 / 禁用、删除等操作。

<Warning>
`ACCESS_TOKEN` 具备机构级数据访问权限，请妥善保管：仅在服务端使用，不要写入客户端代码、日志或版本库。如怀疑泄露，请立即联系 Longport Whale 轮换凭证。
</Warning>
