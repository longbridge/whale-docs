---
title: 鉴权
description: 基于 ACCESS_TOKEN 的请求鉴权
---

BrokerAPI 使用 `ACCESS_TOKEN` 对每个请求进行鉴权：将券商机构的 `ACCESS_TOKEN` 以 `Bearer` 方案放入 `Authorization` 请求头即可。

## 必需请求头

| 请求头 | 取值 | 示例 |
| --- | --- | --- |
| `Authorization` | `Bearer ACCESS_TOKEN` | `Bearer ${access_token}` |
| `Content-Type` | 内容类型 | `application/json; charset=utf-8` |

## 请求示例

```bash cURL
curl --request POST \
  --url https://b-api.longbridge.xyz/v1/datasets/account_cash_balances \
  --header "Authorization: Bearer ${ACCESS_TOKEN}" \
  --header "Content-Type: application/json; charset=utf-8" \
  --data '{"filters": {}, "page": 1, "page_size": 20}'
```

## 获取凭证

`ACCESS_TOKEN` 由 Longport Whale 按券商机构签发（**机构级授权 / Broker-scoped Authorization** —— 覆盖机构获批的数据范围）。

<Warning>
`ACCESS_TOKEN` 具备机构级数据访问权限，请妥善保管：仅在服务端使用，不要写入客户端代码、日志或版本库。如怀疑泄露，请立即联系 Longport Whale 轮换凭证。
</Warning>
