---
title: BrokerAPI
description: 面向 Broker 服务端集成与自研管理后台的机构级 API
---

BrokerAPI 是面向 Broker 的机构级 API，可用于 Server-to-Server 系统集成，也可为 Broker 自研管理后台提供数据与 SaaS 柜台能力。它以 **Broker** 为授权主体，一份凭证覆盖机构获批范围内的能力。

无论用于系统集成还是自研管理后台，实际 API 请求都应由 Broker 控制的服务端发起。Access Key 等机构凭证不得存放在浏览器代码或 Broker App 中；自研管理后台界面应通过 Broker Server 调用 BrokerAPI。

## 一览 {/* at-a-glance */}

| | |
| --- | --- |
| 调用方 | Broker Server、Broker 自研管理后台的服务端 |
| 授权主体 | Broker（**机构级授权 / Broker-scoped Authorization**） |
| 私有数据范围 | 获批的机构范围 |
| 形态 | HTTPS API；支持 Server-to-Server 集成与自研管理后台 |

## 不适用于 {/* not-for */}

- Broker App 使用 WhaleCoreSDK 完全自行实现证券功能 UI —— 请使用 [WhaleCoreSDK 与 TradingAPI](/zh-cn/trading-api/overview)
- 由 Developer Customer 构建第三方应用 —— 请使用 [OpenAPI](https://open.longportapp.com)
- 嵌入移动端交易 UI —— 请使用 [WhaleAppSDK](/zh-cn/whalesdk/whaleapp/overview)
