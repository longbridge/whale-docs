Longport Whale 是面向 Broker 的 SaaS 证券业务系统解决方案。Whale Docs 是统一文档门户，覆盖产品、实施流程、Broker App、Broker Server 与 API 接入方式。

## 文档中的参与方 {/* documentation-participants */}

本文档统一使用以下参与方名称：

| 名称 | 含义 |
| --- | --- |
| **Whale** | **Longport Whale**，本文档中简称 Whale 。 |
| **Broker** | 接入 Whale 的机构，负责自己的产品、Customer 服务及项目上线。 |
| **Customer** | Broker 服务的终端客户，也是 WhaleAppSDK、WhaleCoreSDK 和 TradingAPI 的客户级身份。 |

除历史接口名、配置键和代码字段外，后续页面均使用这三个名称描述参与方。

## 产品 {/* products */}

  <Card title="WhaleSDK" icon="smartphone" href="/zh-cn/whalesdk/overview">
    Whale 客户端 SDK 产品族，包括图形界面 WhaleAppSDK（iOS、Android、WebTrade）和无 UI 数据 SDK WhaleCoreSDK。
  </Card>
  <Card title="BrokerAPI" icon="server" href="/zh-cn/broker-api/overview">
    面向 Broker 的机构级 API，支持 Server-to-Server 集成，也可为 Broker 自研管理后台提供机构数据与 SaaS 柜台能力。
  </Card>
  <Card title="TradingAPI" icon="chart-candlestick" href="/zh-cn/trading-api/overview">
    与无 UI 的 WhaleCoreSDK 配合，供 Broker App 完全自行实现证券功能 UI；覆盖 App 基础机制和 Customer 级 HTTP 业务能力。
  </Card>
  <Card title="OpenAPI" icon="plug" href="https://open.longportapp.com">
    供 Broker 的 Customer 开发策略交易、量化分析和 AI 应用；支持通过 MCP 等 AI-native 方式接入账户资产、行情与基本面能力。
  </Card>
</CardGroup>

## 按角色进入 {/* find-your-entry-point */}

| 你是 | 首要任务 | 入口 |
| --- | --- | --- |
| Broker 决策者 / 产品负责人 | 理解 Whale 能力、实施范围和上线过程 | [Broker 接入总览](/zh-cn/docs/broker-onboarding) |
| Broker 实施团队 | 理解业务流程、准备资料、完成验收 | [Broker 接入总览](/zh-cn/docs/broker-onboarding) |
| Broker App 开发团队 | 集成 WhaleAppSDK（iOS、Android、WebTrade）或 WhaleCoreSDK | [WhaleSDK](/zh-cn/whalesdk/overview) |
| Broker Developer | 以机构身份进行 Server-to-Server 集成或建设自研管理后台 | [BrokerAPI](/zh-cn/broker-api/overview) |
| Broker App Developer | 使用 WhaleCoreSDK 与 TradingAPI 完全自行实现证券功能 UI | [TradingAPI 与 WhaleCoreSDK](/zh-cn/trading-api/overview) |
| Broker 的开发者 Customer / AI 用户 | 开发策略、量化分析，或授权 AI 接入自己的账户与市场数据 | [OpenAPI](https://open.longportapp.com) |
