## 系统要求与安装 {/* requirements-and-installation */}

- iOS 13.0+
- Swift 5.9+、Xcode 15+
- Swift 与 Objective-C

```ruby
platform :ios, '13.0'
use_frameworks! :linkage => :static

target 'YourApp' do
  pod 'WhaleCore'
end
```

WhaleCore 通过私有 CocoaPods 源分发，源地址与访问凭证由接入支持提供。

## 初始化 {/* initialize */}

```swift
import WhaleCore

let config = WhaleCoreConfig(
    logLevel: .info,
    appKey: "your_app_key",
    appSecret: "your_app_secret",
    appId: "your_app_id",
    defaultAccountChannel: "lb_hk",
    token: userAccessToken,
    refreshToken: userRefreshToken,
    language: .zhHans
)
config.tokenDelegate = session
WhaleCoreService.initialize(config: config)
```

项目凭证和默认账户渠道由 Whale 提供；客户的 `token` 与 `refreshToken` 由 Broker 登录流程取得。不要把凭证或完整 token 写入日志。

## Token 与交易鉴权 {/* tokens-and-trade-authentication */}

实现 `WhaleCoreTokenDelegate` 以持久化自动续期后的凭证。可选的 `resolveExpiredToken` 可在 refresh token 也失效时执行静默登录；并发 401 只触发一次恢复，结果共享给挂起请求。

```swift
func didRefreshToken(_ token: String, refreshToken: String) {
    saveSecurely(token, refreshToken)
}

func resolveExpiredToken(completion: @escaping (String?, String?) -> Void) {
    silentLogin { completion($0.token, $0.refreshToken) }
}
```

宿主自行处理交易密码时，将 `tradePasswordEnabled` 设为 `true`，并在初始化前设置 `WhaleCoreTradeAuthDelegate`；否则 SDK 内部处理交易鉴权。

## 生命周期 {/* lifecycle */}

```swift
WhaleCoreService.onResume()
WhaleCoreService.onPause()
WhaleCoreService.logoutAndDestroy()
```

`logoutAndDestroy()` 清除本地 token、断开 WebSocket 并释放服务。切换账号后可再次初始化，但必须重新注册 delegate 和订阅。

## 服务入口 {/* public-services */}

| 服务 | 主要 API |
| --- | --- |
| `quotesService` | `subscribe`、`subscribeKlines`、`getKlines`、`getStock`、期权链与计算器 |
| `orderService` | `submitOrder`、`replaceOrder`、`cancelOrder`、`getTodayOrders`、`getHistoryOrders`、`getOrderDetail` |
| `portfolioService` | 资产订阅、现金明细、持仓行情、会员资产设置 |
| `watchlistService` | 分组与股票增删改、排序、置顶、刷新和实时事件 |
| `requestService` | 自动鉴权与恢复重试的通用 HTTP 透传 |

## 通用 HTTP 请求 {/* general-http-requests */}

需要调用尚未由 WhaleCore 类型化 Service 封装的 [TradingAPI](/zh-cn/trading-api/overview) 时，可以使用 `WhaleCoreService.requestService`。接口路径、参数和响应结构以 TradingAPI 文档为准；宿主提供这些请求信息，WhaleCore 自动补充签名、鉴权、trace 等公共参数与请求头。登录态或 trade token 失效时，SDK 会恢复鉴权并自动重试一次。

`WhaleCoreHTTPRequest` 提供以下属性：

| 属性 | 类型 | 行为 |
| --- | --- | --- |
| `method` | `WhaleCoreHTTPMethod` | `.get`、`.post`、`.put` 或 `.delete` |
| `path` | `String` | 以 `/` 开头的接口路径 |
| `query` | `[String: Any]?` | 仅 GET、DELETE 生效；POST、PUT 会忽略 |
| `body` | `[String: Any]?` | 仅 POST、PUT 生效；GET、DELETE 会忽略 |
| `requiresTradeToken` | `Bool` | 为 `true` 时发送前确保 trade token 有效；默认为 `false` |

响应通过 `bodyString` 提供原始 JSON，通过 `bodyData` 提供 UTF-8 数据，并通过 `headers` 提供响应头。Swift 可直接将响应解码为 `Decodable` 模型。

```swift
struct MemberInfo: Decodable {
    let id: String
    let name: String
}

let request = WhaleCoreHTTPRequest(
    method: .get,
    path: "/v2/member/info"
)
request.query = ["include_accounts": true]

let response = try await WhaleCoreService.requestService.send(request)
let member: MemberInfo = try response.decode()
print(member.name)
```

调用需要交易鉴权的接口时：

```swift
let request = WhaleCoreHTTPRequest(
    method: .get,
    path: "/v5/orders/today"
)
request.requiresTradeToken = true

let response = try await WhaleCoreService.requestService.send(request)
print(response.bodyString)
```

<Note>
  首个版本不支持自定义请求头。请勿通过 `query` 或 `body` 传入签名或鉴权 token；WhaleCore 会通过受管会话自动添加。
</Note>

### 行情订阅 {/* quote-subscription */}

```swift
let subscription = WhaleCoreService.quotesService
    .subscribe(counters: ["ST/US/AAPL", "ST/HK/00700"])
    .detail.depth.trade.preTrade.postTrade
    .start { updates, error in
        updates?.forEach { print($0.counter, $0.stock.lastPrice ?? 0) }
    }

await subscription.cancel()
```

可选数据包括 `list`、`detail`、`depth`、`trade`、`broker`、`preTrade`、`postTrade` 和 `nightTrade`。

### 订单 {/* orders */}

订单请求使用 `clientRequestId` 作为幂等键；重试同一订单必须复用，新订单必须生成新值。公开模型支持限价、市价、LIT、MIT、跟踪止损限价及止盈/止损附带单。

```swift
let common = WhaleCoreOrderCommon(
    counterId: "ST/US/AAPL",
    side: .buy,
    quantity: .byCount(NSDecimalNumber(value: 100)),
    settlementCurrency: "USD",
    clientRequestId: UUID().uuidString
)
let request = WhaleCoreOrderSubmitRequest.limit(
    common: common,
    kind: .lo,
    price: NSDecimalNumber(string: "180")
)
let result = try await WhaleCoreService.orderService.submitOrder(request)
```

订单推送通过 `addDelegate` / `removeDelegate` 管理：首个 delegate 自动启动，最后一个移除后自动停止。
