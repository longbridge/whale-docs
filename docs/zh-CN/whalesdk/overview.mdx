WhaleSDK 是 Whale 面向 Broker 提供的客户端证券交易 SDK 产品族，覆盖行情、资产、交易、自选和资讯等核心业务能力，让 Broker App 或网站无需从零搭建证券业务系统即可上线交易服务。

## 怎么选 {/* how-to-choose */}

两种产品的核心区别在于：证券业务的图形界面由谁来做。

| 你的情况 | 建议选择 |
| --- | --- |
| 希望尽快上线，不想自己设计和开发证券业务页面 | **WhaleAppSDK** —— 提供开箱即用的完整图形界面 |
| 需要完全自定义的交互与视觉体验，愿意自建证券业务 UI | **WhaleCore** —— 只提供无 UI 的数据与交易能力，界面由 Broker App 自行实现 |

|  | WhaleAppSDK | WhaleCore |
| --- | --- | --- |
| 图形界面 | 完整证券业务 UI | 不含 UI，由 Broker App 自行实现 |
| 支持平台 | iOS、Android、Web | iOS、Android、Web、Flutter |

## 共同前提 {/* shared-prerequisite */}

无论选择哪种产品，Broker App 都需要先完成客户在 Broker 侧的登录，再由 Broker 服务端向 Whale 服务端换取用户凭证并传入 SDK；WhaleCore 之上还可以配合 [TradingAPI](/zh-cn/trading-api/overview) 调用尚未被类型化 Service 覆盖的接口。
