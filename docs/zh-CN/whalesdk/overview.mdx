**WhaleSDK** 是 Whale 客户端 SDK 产品族的总称。Broker 根据是否需要现成图形界面以及目标平台，选择其中的具体产品。

| 产品              | 图形界面        | 平台                                    | 适用场景                                     |
| ----------------- | --------------- | --------------------------------------- | -------------------------------------------- |
| **WhaleAppSDK**  | 完整证券业务 UI | iOS、Android、WebTrade                  | 在 Broker App、网站或 Web 容器中集成图形界面 |
| **WhaleCoreSDK** | 不含 UI         | iOS、Android 已可用；WebAssembly 开发中 | Broker App 完全自行实现证券功能 UI           |

## WhaleAppSDK {/* whaleappsdk */}

WhaleAppSDK 提供已经实现的证券业务图形界面和业务功能，包含三个平台形态：

- [WhaleAppSDK for iOS](/zh-cn/whalesdk/whaleapp/ios)
- [WhaleAppSDK for Android](/zh-cn/whalesdk/whaleapp/android)
- [WhaleAppSDK WebTrade](/zh-cn/whalesdk/whaleapp/web)
- [产品能力与页面示例](/zh-cn/whalesdk/whaleapp/capabilities)
- [技术 FAQ 与参考性能数据](/zh-cn/whalesdk/whaleapp/faq)
- [移动端共同接入流程](/zh-cn/whalesdk/whaleapp/overview)

Broker App 还需要接入系统消息通知，并将标准消息体交给 WhaleAppSDK。服务端渠道、云推送凭证和客户端责任见 [消息推送接入](/zh-cn/docs/message-push)。

### WebTrade {/* webtrade */}

WebTrade 是 WhaleAppSDK 的 Web 图形界面形态，相当于 iOS/Android App 的 Web 版本。WebTrade 支持独立域名部署供用户直接访问，或以 iframe 方式嵌入 Broker 官网；两种方式均通过 Cookie 与 `postMessage` 完成 SSO 和页面通信。WebTrade 还支持以 PWA 方式安装到桌面。

## WhaleCoreSDK {/* whalecoresdk */}

WhaleCoreSDK 是 WhaleSDK 中不含图形界面的数据 SDK，提供行情订阅、WebSocket、认证签名和 token 自动续期等基础机制。Broker App 使用 WhaleCoreSDK 与 TradingAPI 组合，完全自行实现证券功能 UI 和业务流程。

请先阅读 [WhaleCoreSDK Overview](/zh-cn/whalesdk/whalecore/overview)，再进入 [iOS](/zh-cn/whalesdk/whalecore/ios) 或 [Android](/zh-cn/whalesdk/whalecore/android) 指南。
