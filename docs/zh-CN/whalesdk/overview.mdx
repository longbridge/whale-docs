**Whale SDK** 是 Whale 客户端 SDK 产品族的总称。Broker 根据是否需要现成图形界面以及目标平台，选择其中的具体产品。

| 产品 | 图形界面 | 平台 | 适用场景 |
| --- | --- | --- | --- |
| **WhaleApp SDK** | 完整证券业务 UI | iOS、Android、WebTrade | 在 Broker App、网站或 Web 容器中集成图形界面 |
| **WhaleCore SDK** | 不含 UI | iOS、Android 已可用；WebAssembly 开发中 | Broker App 完全自行实现证券功能 UI |

## WhaleApp SDK

WhaleApp SDK 提供已经实现的证券业务图形界面和业务功能，包含三个平台形态：

- [WhaleApp SDK for iOS](/zh-cn/whalesdk/ios/)
- [WhaleApp SDK for Android](/zh-cn/whalesdk/android/)
- [WhaleApp SDK WebTrade](/zh-cn/whalesdk/webtrade/)
- [产品能力与页面示例](/zh-cn/whalesdk/capabilities/)
- [技术 FAQ 与参考性能数据](/zh-cn/whalesdk/technical-faq/)
- [移动端共同接入流程](/zh-cn/whalesdk/mobile-integration/)
- [可选半公开接口](/zh-cn/whalesdk/optional-apis/)

Broker App 还需要接入系统消息通知，并将标准消息体交给 WhaleApp SDK。服务端渠道、云推送凭证和客户端责任见[消息推送接入](/zh-cn/docs/message-push/)。

### WebTrade

WebTrade 是 WhaleApp SDK 的 Web 图形界面形态。Broker 可以通过新标签页、iframe 或 WebView 接入，并使用 Cookie 与 `postMessage` 完成 SSO 和页面通信。

## WhaleCore SDK

WhaleCore SDK 是 Whale SDK 中不含图形界面的数据 SDK，提供行情订阅、WebSocket、认证签名和 token 自动续期等基础机制。Broker App 使用 WhaleCore SDK 与 Trading API 组合，完全自行实现证券功能 UI 和业务流程。

请先阅读 [WhaleCore SDK Overview](/zh-cn/whalesdk/core-overview/)，再进入 [iOS](/zh-cn/whalesdk/core-ios/) 或 [Android](/zh-cn/whalesdk/core-android/) 指南。
