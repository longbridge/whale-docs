## 交付与兼容性

<AccordionGroup>
  <Accordion title="SDK 如何交付？是否包含源码？">Android 使用 `.aar`，iOS 使用 `.xcframework`，均为不含源码的二进制包。</Accordion>
  <Accordion title="是否支持动态下发或热更新？">不支持，更新需要发布新的 Broker App 版本。接入阶段可高频提供构建；上线后按约定节奏发布功能版本并优先处理紧急缺陷，通常并行维护线上版本与下一个开发版本。</Accordion>
  <Accordion title="会增加多少包体积？">参考构建中 Android 约增加 80 MB，iOS 约增加 90 MB，其中 20 MB 以上可能是可选的 H5 离线包。不内置时，启动后下载完成前 H5 页面会较慢。实际体积因构建而异。</Accordion>
  <Accordion title="如何处理依赖冲突与开源许可？">容易冲突的库会被隔离或定制，可使用 SDK 内置版本或按 [Android 指南](/cn/whalesdk/android)排除间接依赖。正式接入时会提供完整依赖名称、版本和许可清单。</Accordion>
  <Accordion title="接口是否向下兼容？">会尽量保持旧接口兼容；无法避免的破坏性变更会在发布说明中标注。</Accordion>
</AccordionGroup>
