WhaleAppSDK 的当前 iOS 和 Android 版本提供分析事件回调。是否启用、允许转发哪些事件及属性，仍应由 Broker 与 Whale 项目团队在交付范围内确认。

<Warning>
不要把 token、refresh token、Customer 身份资料、账户号码或其他敏感信息添加到分析事件。Broker App 只应消费双方明确约定且稳定的事件。
</Warning>

## Android

```kotlin
LBWhaleApp.callback = object : LBWhaleAppCallback {
    override fun onLBWhaleAppAnalyticsEvent(
        eventName: String,
        properties: org.json.JSONObject
    ) {
        // 仅转发项目约定的事件和属性
    }
}
```

## iOS

```objective-c
- (void)lbWhaleAppAnalyticsEventWithName:(NSString *)name
                              properties:(NSDictionary *)properties {
    // 仅转发项目约定的事件和属性
}
```

## 事件范围

常见基础事件包括：

- `$AppViewScreen`：显示页面。
- `$AppPageLeave`：离开页面。
- `$AppClick`：点击。
- `whale_sdk_*`：Broker App 调用 SDK 接口以及 SDK 生命周期回调，例如 `whale_sdk_start`、`whale_sdk_start_success` 和 `whale_sdk_start_callback_run`。

SDK 内部还可能产生社区内容曝光、搜索结果曝光和资讯流曝光等业务事件。这些内部事件不保证对 Broker 稳定，除非项目交付范围明确约定，否则不应依赖或转发。
