WhaleAppSDK 可在 Broker App 中嵌入一套可投入生产的证券业务体验，包括界面、导航、登录衔接、行情展示和交易流程；Broker 仍保留自己的账户体系和 App 外壳。

## 产品模块 {/* included-modules */}

| 模块 | 典型能力 |
| --- | --- |
| 行情 | 市场概览、搜索、报价、图表、盘口和标的详情 |
| 自选 | 自选分组、标的同步和详情导航 |
| 交易 | 港美股下单、订单状态、持仓、资产和成交记录 |
| 内容 | 市场与个股资讯、内容发现和可选社区体验 |

## 定制与交付 {/* customization-and-delivery */}

项目级定制包括图标、颜色、皮肤、浅色/深色/跟随系统主题、英文/简体中文/繁体中文、涨跌颜色模式、自定义字体和消息推送方式。部分能力需要项目构建而非运行时配置。

- **iOS 与 Android：**嵌入 Broker App 的原生 SDK 包。
- **WebTrade：**支持独立域名部署或以 `iframe` 方式嵌入 Broker 官网，通过 WhaleAppSDK 的 JavaScript 库完成 SSO 与偏好同步；支持 PWA 安装到桌面。

请继续阅读 [移动端共同接入流程](/zh-cn/whalesdk/whaleapp/overview)，再进入 [iOS](/zh-cn/whalesdk/whaleapp/ios) 或 [Android](/zh-cn/whalesdk/whaleapp/android) 指南。
