Longport Whale 是面向 Broker 的 SaaS 證券業務系統解決方案。Whale Docs 是統一文件門戶，覆蓋產品、實施流程、Broker App、Broker Server 與 API 接入方式。

## 文件中的參與方

本文件統一使用以下參與方名稱：

| 名稱 | 含義 |
| --- | --- |
| **Whale** | **Longport Whale**，本文件中簡稱 Whale 。 |
| **Broker** | 接入 Whale 的機構，負責自己的產品、Customer 服務及專案上線。 |
| **Customer** | Broker 服務的終端客戶，也是 WhaleApp SDK、WhaleCore SDK 和 Trading API 的客戶級身份。 |

除歷史介面名、配置鍵和程式碼欄位外，後續頁面均使用這三個名稱描述參與方。

## 按角色進入

| 你是 | 首要任務 | 入口 |
| --- | --- | --- |
| Broker 決策者 / 產品負責人 | 理解 Whale 能力、實施範圍和上線過程 | [Broker 接入總覽](/zh-hk/docs/broker-onboarding) |
| Broker 實施團隊 | 理解業務流程、準備資料、完成驗收 | [Broker 接入總覽](/zh-hk/docs/broker-onboarding) |
| Broker App 開發團隊 | 整合 WhaleApp SDK（iOS、Android、WebTrade）或 WhaleCore SDK | [Whale SDK](/zh-hk/whalesdk/overview) |
| Broker Developer | 以機構身份進行 Server-to-Server 整合或建設自研管理後臺 | [Broker API](/zh-hk/broker-api/overview) |
| Broker App Developer | 使用 WhaleCore SDK 與 Trading API 完全自行實現證券功能 UI | [Trading API 與 WhaleCore SDK](/zh-hk/trading-api/introduction) |
| Broker 的開發者 Customer / AI 使用者 | 開發策略、量化分析，或授權 AI 接入自己的帳戶與市場資料 | [OpenAPI](https://open.longportapp.com) |
