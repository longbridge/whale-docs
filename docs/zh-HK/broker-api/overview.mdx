BrokerAPI 是面向 Broker 的機構級 API，可用於 Server-to-Server 系統整合，也可為 Broker 自研管理後臺提供資料與 SaaS 櫃檯能力。它以 **Broker** 為授權主體，一份憑證覆蓋機構獲批範圍內的能力。

無論用於系統整合還是自研管理後臺，實際 API 請求都應由 Broker 控制的服務端發起。Access Key 等機構憑證不得存放在瀏覽器程式碼或 Broker App 中；自研管理後臺介面應透過 Broker Server 呼叫 BrokerAPI。

<Warning>
BrokerAPI 仍在建設中。本文檔可用於了解能力範圍和規劃整合，但介面路徑、欄位和可用範圍仍可能調整，不代表最終開放的介面契約。如果按當前文檔直接開發，後續可能需要返工。開始開發前，請與 Whale 專案團隊確認所需介面的當前狀態和獲批範圍。
</Warning>

## 一覽 {/* at-a-glance */}

|              |                                                        |
| ------------ | ------------------------------------------------------ |
| 呼叫方       | Broker Server、Broker 自研管理後臺的服務端             |
| 授權主體     | Broker（**機構級授權 / Broker-scoped Authorization**） |
| 私有資料範圍 | 獲批的機構範圍                                         |
| 形態         | HTTPS API；支援 Server-to-Server 整合與自研管理後臺    |

## API 路徑分類 {/* api-families */}

BrokerAPI 包含兩類來源的能力：專門設計的 Server-to-Server 介面，以及從 Whale Console 現有業務流程整理並開放的介面。你可以透過請求路徑了解介面的設計方式：

| 路徑特徵                | 定位                                                                                       | 常見能力                         |
| ----------------------- | ------------------------------------------------------------------------------------------ | -------------------------------- |
| 包含 `/whaleapi/`       | 最初為 Whale 租戶的服務端與 Whale 對接而設計，已在生產環境長期使用，並持續服務實際對接。   | 直接的 Server-to-Server 查詢和業務操作 |
| 包含 `/datasets/`       | 從 Whale Console 現有能力整理並開放，大部分建基於通用配置的 Dataset 框架。                 | 列表查詢、篩選、分頁和可選匯出   |
| 其他路徑                | Whale Console 個別功能使用的獨立介面，適用於不適合 Dataset 模型的業務。                    | 狀態修改、流程操作和詳情查詢     |

這項分類說明介面的設計來源，不代表新舊或建議優先次序。不同類型的 API 彼此互補，請按所需數據和業務流程選擇具體介面。

Dataset 查詢 API 是唯讀介面，預設使用 `GET`。如果編碼後的篩選條件和其他查詢參數太大，不適合放在 URL query string 中，可以將相同參數作為 JSON body，透過 `POST` 請求同一路徑。兩種方式都不會修改業務數據。

## 不適用於 {/* not-for */}

- Broker App 使用 WhaleCoreSDK 完全自行實現證券功能 UI —— 請使用 [WhaleCoreSDK 與 TradingAPI](/zh-hk/trading-api/overview)
- 由開發者構建第三方應用 —— 請使用 [OpenAPI](https://open.longportapp.com)
- 嵌入移動端交易 UI —— 請使用 [WhaleAppSDK](/zh-hk/whalesdk/whaleapp/overview)
