---
title: BrokerAPI
description: 面向 Broker 服務端整合與自研管理後臺的機構級 API
---

BrokerAPI 是面向 Broker 的機構級 API，可用於 Server-to-Server 系統整合，也可為 Broker 自研管理後臺提供資料與 SaaS 櫃檯能力。它以 **Broker** 為授權主體，一份憑證覆蓋機構獲批範圍內的能力。

無論用於系統整合還是自研管理後臺，實際 API 請求都應由 Broker 控制的服務端發起。Access Key 等機構憑證不得存放在瀏覽器程式碼或 Broker App 中；自研管理後臺介面應透過 Broker Server 呼叫 BrokerAPI。

## 一覽 {/* at-a-glance */}

|              |                                                        |
| ------------ | ------------------------------------------------------ |
| 呼叫方       | Broker Server、Broker 自研管理後臺的服務端             |
| 授權主體     | Broker（**機構級授權 / Broker-scoped Authorization**） |
| 私有資料範圍 | 獲批的機構範圍                                         |
| 形態         | HTTPS API；支援 Server-to-Server 整合與自研管理後臺    |

## 不適用於 {/* not-for */}

- Broker App 使用 WhaleCoreSDK 完全自行實現證券功能 UI —— 請使用 [WhaleCoreSDK 與 TradingAPI](/zh-hk/trading-api/overview)
- 由開發者構建第三方應用 —— 請使用 [OpenAPI](https://open.longportapp.com)
- 嵌入移動端交易 UI —— 請使用 [WhaleAppSDK](/zh-hk/whalesdk/whaleapp/overview)
