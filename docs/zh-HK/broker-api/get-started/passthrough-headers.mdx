---
title: 透傳請求標頭
description: 由網關原樣轉發至後端服務的請求標頭
---

以下請求標頭由網關原樣透傳給後端服務，不作任何修改。透過設置這些請求標頭可控制回應語言、客戶端平台及版本相關的業務行為。

## accept-language {/* accept-language */}

指定回應內容的偏好語言。缺省時回退到系統預設語言。

| 取值 | 語言 |
| --- | --- |
| `zh-CN` | 簡體中文 |
| `zh-HK` | 繁體中文 |
| `en` | 英文 |

## x-platform {/* x-platform */}

標識請求來源的客戶端平台。

| 取值 | 平台 |
| --- | --- |
| `ios` | iOS |
| `android` | Android |
| `web` | Web |

## x-app-version {/* x-app-version */}

標識客戶端應用版本，例如 `3.28.0`。用於版本相關的業務邏輯及會話元數據。

## x-timestamp {/* x-timestamp */}

攜帶請求時間戳。
