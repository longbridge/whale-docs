---
title: 請求標頭
description: 由網關原樣轉發至後端服務的請求標頭
---

以下請求標頭由網關原樣透傳給後端服務，不作任何修改。

## Content-Type {/* content-type */}

指定請求內容格式。請求內容為 JSON 時使用 `application/json`。

## Accept-Language {/* accept-language */}

指定回應內容的偏好語言。缺省時回退到系統預設語言。

| 取值 | 語言 |
| --- | --- |
| `en` | 英文 |
| `zh-CN` | 簡體中文 |
| `zh-HK` | 繁體中文 |

## X-Timestamp {/* x-timestamp */}

攜帶請求時間戳。
