## 1. 準備憑證 {/* 1-prepare-credentials */}

你需要為券商機構簽發的一項憑證：

| 憑證 | 請求標頭 | 說明 |
| --- | --- | --- |
| `ACCESS_TOKEN` | `Authorization: Bearer <token>` | 由 Longport Whale 簽發的機構級訪問令牌 |

## 2. 發起第一個請求 {/* 2-send-your-first-request */}

以下範例查詢 `account_cash_balances` 資料集（`GET /v1/datasets/account_cash_balances`）：

```bash cURL
curl --get \
  --url https://b-api.longbridge.xyz/v1/datasets/account_cash_balances \
  --header "Authorization: Bearer ${ACCESS_TOKEN}" \
  --data-urlencode 'filters={}' \
  --data-urlencode 'page=1' \
  --data-urlencode 'page_size=20'
```

```python Python
import requests

ACCESS_TOKEN = "${access_token}"

host = "https://b-api.longbridge.xyz"  # 生產環境：https://b-api.lbkrs.com
uri = "/v1/datasets/account_cash_balances"

resp = requests.get(
    url=host + uri,
    headers={"Authorization": f"Bearer {ACCESS_TOKEN}"},
    params={"filters": "{}", "page": 1, "page_size": 20},
)
print(resp.json())
```

<Tip>
切換測試 / 生產環境只需修改 `host` —— 測試環境 `https://b-api.longbridge.xyz` 不會影響真實資料。
</Tip>
