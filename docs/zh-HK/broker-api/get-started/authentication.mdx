---
title: 鑑權
description: 基於 ACCESS_TOKEN 的請求鑑權
---

BrokerAPI 使用 `ACCESS_TOKEN` 對每個請求進行鑑權：將券商機構的 `ACCESS_TOKEN` 以 `Bearer` 方案放入 `Authorization` 請求標頭即可。

## 必需請求標頭 {/* required-headers */}

| 請求標頭 | 取值 | 範例 |
| --- | --- | --- |
| `Authorization` | `Bearer ACCESS_TOKEN` | `Bearer ${access_token}` |
| `Content-Type` | 內容類型 | `application/json; charset=utf-8` |

## 請求範例 {/* example-request */}

```bash cURL
curl --request POST \
  --url https://b-api.longbridge.xyz/v1/datasets/account_cash_balances \
  --header "Authorization: Bearer ${ACCESS_TOKEN}" \
  --header "Content-Type: application/json; charset=utf-8" \
  --data '{"filters": {}, "page": 1, "page_size": 20}'
```

## 取得憑證 {/* obtaining-credentials */}

`ACCESS_TOKEN` 為機構級憑證（**機構級授權 / Broker-scoped Authorization** —— 覆蓋機構獲批的資料範圍），由機構管理員在後台自助建立：

1. 進入 **全域設定 → 身份管理 → API Token**。
2. 點擊右上角 **新建 Token**，在 **建立 Access Token** 彈窗中填寫：
   - **名稱**：便於識別用途（例如：對賬服務、行情同步）。2–30 個字元；名稱同時作為 service 賬號名，**租戶內唯一，且刪除後不可重用**。
   - **過期時間**：按需選擇（如 `1 天`）。
3. 點擊 **建立**。系統會**一次性**顯示完整 `ACCESS_TOKEN`，請立即複製並妥善保存；**彈窗關閉後無法再次查看，遺失後只能重新建立**。

建立後可在 API Token 列表查看密鑰名稱、密鑰前綴、狀態、過期時間、最近使用時間 / IP、建立時間，並對每個 Token 執行編輯、重置 Token、啟用 / 停用、刪除等操作。

<Warning>
`ACCESS_TOKEN` 具備機構級資料存取權限，請妥善保管：僅在服務端使用，不要寫入客戶端代碼、日誌或版本庫。如懷疑洩露，請立即聯絡 Longport Whale 輪換憑證。
</Warning>
