Whale Console 是營運 Longport Whale 的後台控制台。其使用手冊涵蓋整個控制台的日常櫃檯業務、審核、設定和監控。

<Note>
存取需要 IP 白名單。Broker 完成 Onboarding 後，Whale 會為其開通白名單存取；Whale Console 本身也僅限白名單 IP 存取。
</Note>

## 存取前提 {/* before-you-can-access */}

- 完成 Broker Onboarding，參見 [Broker 上線](/zh-hk/docs/broker-onboarding)。
- 由 Whale 為你的機構開通 IP 白名單存取。
- 在白名單網路環境下存取控制台及其手冊。

## 開啟 Whale Console 手冊 {/* open-the-manual */}

開通存取後，開啟手冊：

[開啟 Whale Console 手冊](https://docs.longportwhale.com/zh-hk/docs/)

如果連結無法開啟，通常是你的 IP 尚未加入白名單。請聯絡專案團隊確認 Onboarding 狀態與白名單設定。
