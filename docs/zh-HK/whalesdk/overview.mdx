WhaleSDK 是 Whale 面向 Broker 提供的客戶端證券交易 SDK 產品族，覆蓋行情、資產、交易、自選和資訊等核心業務能力，讓 Broker App 或網站無需從零搭建證券業務系統即可上線交易服務。

## 怎麼選 {/* how-to-choose */}

兩種產品的核心區別在於：證券業務的圖形介面由誰來做。

| 你的情況 | 建議選擇 |
| --- | --- |
| 希望儘快上線，不想自己設計和開發證券業務頁面 | **WhaleAppSDK** —— 提供開箱即用的完整圖形介面 |
| 需要完全自訂的互動與視覺體驗，願意自建證券業務 UI | **WhaleCore** —— 只提供無 UI 的資料與交易能力，介面由 Broker App 自行實現 |

|  | WhaleAppSDK | WhaleCore |
| --- | --- | --- |
| 圖形介面 | 完整證券業務 UI | 不含 UI，由 Broker App 自行實現 |
| 支援平臺 | iOS、Android、Web | iOS、Android、Web、Flutter |

## 共同前提 {/* shared-prerequisite */}

無論選擇哪種產品，Broker App 都需要先完成客戶在 Broker 側的登入，再由 Broker 服務端向 Whale 服務端換取使用者憑證並傳入 SDK；WhaleCore 之上還可以配合 [TradingAPI](/zh-hk/trading-api/overview) 呼叫尚未被型別化 Service 覆蓋的介面。
