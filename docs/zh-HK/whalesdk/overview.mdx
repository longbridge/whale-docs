**Whale SDK** 是 Whale 客戶端 SDK 產品族的總稱。Broker 根據是否需要現成圖形介面以及目標平臺，選擇其中的具體產品。

| 產品 | 圖形介面 | 平臺 | 適用場景 |
| --- | --- | --- | --- |
| **WhaleApp SDK** | 完整證券業務 UI | iOS、Android、WebTrade | 在 Broker App、網站或 Web 容器中整合圖形介面 |
| **WhaleCore SDK** | 不含 UI | iOS、Android 已可用；WebAssembly 開發中 | Broker App 完全自行實現證券功能 UI |

## WhaleApp SDK

WhaleApp SDK 提供已經實現的證券業務圖形介面和業務功能，包含三個平臺形態：

- [WhaleApp SDK for iOS](/zh-Hant/whalesdk/ios)
- [WhaleApp SDK for Android](/zh-Hant/whalesdk/android)
- [WhaleApp SDK WebTrade](/zh-Hant/whalesdk/webtrade)
- [產品能力與頁面範例](/zh-Hant/whalesdk/capabilities)
- [技術 FAQ 與參考效能數據](/zh-Hant/whalesdk/technical-faq)
- [移動端共同接入流程](/zh-Hant/whalesdk/mobile-integration)
- [可選半公開介面](/zh-Hant/whalesdk/optional-apis)

Broker App 還需要接入系統訊息通知，並將標準訊息體交給 WhaleApp SDK。服務端渠道、雲推送憑證和客戶端責任見[訊息推送接入](/zh-Hant/docs/message-push)。

### WebTrade

WebTrade 是 WhaleApp SDK 的 Web 圖形介面形態。Broker 可以透過新標籤頁、iframe 或 WebView 接入，並使用 Cookie 與 `postMessage` 完成 SSO 和頁面通訊。

## WhaleCore SDK

WhaleCore SDK 是 Whale SDK 中不含圖形介面的資料 SDK，提供行情訂閱、WebSocket、認證簽名和 token 自動續期等基礎機制。Broker App 使用 WhaleCore SDK 與 Trading API 組合，完全自行實現證券功能 UI 和業務流程。
