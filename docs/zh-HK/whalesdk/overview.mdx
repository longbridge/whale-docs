**WhaleSDK** 是 Whale 客戶端 SDK 產品族的總稱。Broker 根據是否需要現成圖形介面以及目標平臺，選擇其中的具體產品。

| 產品              | 圖形介面        | 平臺                                    | 適用場景                                     |
| ----------------- | --------------- | --------------------------------------- | -------------------------------------------- |
| **WhaleAppSDK**  | 完整證券業務 UI | iOS、Android、WebTrade                  | 在 Broker App、網站或 Web 容器中整合圖形介面 |
| **WhaleCoreSDK** | 不含 UI         | iOS、Android 已可用；WebAssembly 開發中 | Broker App 完全自行實現證券功能 UI           |

## WhaleAppSDK {/* whaleappsdk */}

WhaleAppSDK 提供已經實現的證券業務圖形介面和業務功能，包含三個平臺形態：

- [WhaleAppSDK for iOS](/zh-hk/whalesdk/whaleapp/ios)
- [WhaleAppSDK for Android](/zh-hk/whalesdk/whaleapp/android)
- [WhaleAppSDK WebTrade](/zh-hk/whalesdk/whaleapp/web)
- [產品能力與頁面範例](/zh-hk/whalesdk/whaleapp/capabilities)
- [技術 FAQ 與參考效能數據](/zh-hk/whalesdk/whaleapp/faq)
- [移動端共同接入流程](/zh-hk/whalesdk/whaleapp/overview)
- [可選半公開介面](/zh-hk/whalesdk/whaleapp/optional-apis)

Broker App 還需要接入系統訊息通知，並將標準訊息體交給 WhaleAppSDK。服務端渠道、雲推送憑證和客戶端責任見 [訊息推送接入](/zh-hk/docs/message-push)。

### WebTrade {/* webtrade */}

WebTrade 是 WhaleAppSDK 的 Web 圖形介面形態。Broker 可以透過新標籤頁、iframe 或 WebView 接入，並使用 Cookie 與 `postMessage` 完成 SSO 和頁面通訊。

## WhaleCoreSDK {/* whalecoresdk */}

WhaleCoreSDK 是 WhaleSDK 中不含圖形介面的資料 SDK，提供行情訂閱、WebSocket、認證簽名和 token 自動續期等基礎機制。Broker App 使用 WhaleCoreSDK 與 TradingAPI 組合，完全自行實現證券功能 UI 和業務流程。

請先閱讀 [WhaleCoreSDK Overview](/zh-hk/whalesdk/whalecore/overview)，再進入 [iOS](/zh-hk/whalesdk/whalecore/ios) 或 [Android](/zh-hk/whalesdk/whalecore/android) 指南。
