---
title: 產品能力
description: 產品模組、客製能力與頁面範例
---

WhaleAppSDK 可在 Broker App 中嵌入一套可投入生產的證券業務體驗，包括介面、導覽、登入銜接、行情展示和交易流程；Broker 仍保留自己的帳戶體系和 App 外殼。

## 產品模組

| 模組 | 典型能力 |
| --- | --- |
| 行情 | 市場概覽、搜尋、報價、圖表、盤口和標的詳情 |
| 自選 | 自選分組、標的同步和詳情導覽 |
| 交易 | 港美股下單、訂單狀態、持倉、資產和成交記錄 |
| 內容 | 市場與個股資訊、內容發現和可選社群體驗 |

## 客製與交付

專案級客製包括圖示、顏色、外觀、淺色/深色/跟隨系統主題、英文/簡體中文/繁體中文、升跌顏色模式、自訂字型和訊息推播方式。部分能力需要專案建置而非執行階段配置。

- **iOS 與 Android：**嵌入 Broker App 的原生 SDK 套件。
- **WebTrade：**透過瀏覽器分頁、`iframe` 或 WebView 接入，並完成 SSO 和頁面通訊。

請繼續閱讀[移動端共同接入流程](/zh-hk/whalesdk/whaleapp/overview)，再進入 [iOS](/zh-hk/whalesdk/whaleapp/ios) 或 [Android](/zh-hk/whalesdk/whaleapp/android) 指南。
