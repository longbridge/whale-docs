## 交付與相容性

<AccordionGroup>
  <Accordion title="SDK 如何交付？是否包含原始碼？">Android 使用 `.aar`，iOS 使用 `.xcframework`，均為不含原始碼的二進位套件。</Accordion>
  <Accordion title="是否支援動態下發或熱更新？">不支援，更新需要發布新的 Broker App 版本。接入階段可高頻提供建置；上線後按約定節奏發布功能版本並優先處理緊急缺陷，通常並行維護線上版本與下一個開發版本。</Accordion>
  <Accordion title="會增加多少套件大小？">參考建置中 Android 約增加 80 MB，iOS 約增加 90 MB，其中 20 MB 以上可能是可選的 H5 離線套件。不內置時，啟動後下載完成前 H5 頁面會較慢。實際大小因建置而異。</Accordion>
  <Accordion title="如何處理依賴衝突與開源授權？">容易衝突的程式庫會被隔離或客製，可使用 SDK 內置版本或按 [Android 指南](/zh-hk/whalesdk/whaleapp/android)排除間接依賴。正式接入時會提供完整依賴名稱、版本和授權清單。</Accordion>
  <Accordion title="介面是否向下相容？">會盡量保持舊介面相容；無法避免的破壞性變更會在發布說明中標示。</Accordion>
</AccordionGroup>
