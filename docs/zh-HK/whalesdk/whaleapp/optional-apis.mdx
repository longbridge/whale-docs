description: WhaleAppSDK 分析事件轉發及專案約定範圍

WhaleAppSDK 的當前 iOS 和 Android 版本提供分析事件回調。是否啟用、允許轉發哪些事件及屬性，仍應由 Broker 與 Whale 專案團隊在交付範圍內確認。

<Warning>
不要把 token、refresh token、客戶身份資料、帳戶號碼或其他敏感資訊新增到分析事件。Broker App 只應消費雙方明確約定且穩定的事件。
</Warning>

## Android {/* android */}

```kotlin
LBWhaleApp.callback = object : LBWhaleAppCallback {
    override fun onLBWhaleAppAnalyticsEvent(
        eventName: String,
        properties: org.json.JSONObject
    ) {
        // 僅轉發專案約定的事件和屬性
    }
}
```

## iOS {/* ios */}

```objective-c
- (void)lbWhaleAppAnalyticsEventWithName:(NSString *)name
                              properties:(NSDictionary *)properties {
    // 僅轉發專案約定的事件和屬性
}
```

## 事件範圍 {/* event-scope */}

常見基礎事件包括：

- `$AppViewScreen`：顯示頁面。
- `$AppPageLeave`：離開頁面。
- `$AppClick`：點擊。
- `whale_sdk_*`：Broker App 呼叫 SDK 介面以及 SDK 生命週期回調，例如 `whale_sdk_start`、`whale_sdk_start_success` 和 `whale_sdk_start_callback_run`。

SDK 內部還可能產生社群內容曝光、搜尋結果曝光和資訊流曝光等業務事件。這些內部事件不保證對 Broker 穩定，除非專案交付範圍明確約定，否則不應依賴或轉發。
