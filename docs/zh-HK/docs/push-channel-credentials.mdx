本文件是 Whale 託管推送方案的資料收集模板，用於確認 Broker App 在 UAT 與生產環境需要開通的 Android 廠商渠道和 iOS APNs 配置。

<Warning>
本頁只定義需要收集的欄位，不應直接填寫並提交真實金鑰。證書、密碼、Client Secret 和服務賬號金鑰必須透過雙方批准的秘密交付渠道傳輸，並記錄環境、保管人、有效期和輪換方式。
</Warning>

## 填寫規則 {/* completion-rules */}

1. 生產與 UAT 必須分別確認 App 標識和渠道配置。
2. 兩個環境的 Android Package Name 相同時，只填寫生產資訊，UAT 填寫“無”。
3. 不需要的推送渠道在“資訊”列填寫“無”，不要留空。
4. iOS 的 `.p12` 與 `.p8` 只需選擇一種；未提供的憑證列刪除。
5. 每份憑證都應註明有效期和負責輪換的 Broker 聯絡人。
