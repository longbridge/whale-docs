<Note>
本頁保留歷史對接結論，便於實施時追溯。涉及環境地址、限頻和業務規則的內容可能按專案調整，上線前應與 Whale 專案團隊再次確認。
</Note>

<AccordionGroup>
  <Accordion title="提交開戶申請後多久能完成？建議多久查詢一次？">
    如果專案配置為無需人工審批、直接完成開戶，後臺仍透過非同步任務處理。實際耗時取決於當前併發量，可每隔數秒查詢一次。具體輪詢間隔和限頻需以專案配置為準。
  </Accordion>

  <Accordion title="出入金介面的 bizCode 是什麼？金額如何傳遞？">
    業務碼請參考 [BrokerAPI 資產介面](https://apidocs.longbridgewhale.com/whaleapi/asset-348068f0)。出金和入金的金額都傳正數，透過 `direction` 區分方向。
  </Accordion>

  <Accordion title="出入金金額支援多少位小數？">
    最高支援兩位小數，帳戶中的金額也按兩位小數儲存。
  </Accordion>

  <Accordion title="介面錯誤應該看 HTTP 狀態還是響應體 code？">
    歷史介面在發生錯誤時可能返回 HTTP `400`，響應體中同時提供 `404002`、`404102` 等業務錯誤碼；業務判斷以響應體 `code` 為準。正常請求返回 HTTP `200`，響應體 `code` 為 `0`。
  </Accordion>

  <Accordion title="UAT 環境域名是什麼？">
    歷史材料記錄的地址為 `https://api.longbridgewhale.com`。配置出網前需向 Whale 專案團隊確認當前專案的實際環境地址。
  </Accordion>

  <Accordion title="調賬前是否需要凍結資金？">
    不需要。直接呼叫調賬介面，不要呼叫凍結資金介面；凍結介面並非為調賬設計。歷史實現中，調賬出賬不校驗風控，可能發生超額出賬，因此呼叫方必須自行控制可用金額和額度。
  </Accordion>

  <Accordion title="多個市場或上手方是否需要由 Broker 區分？">
    Broker 不需要關心後續上手方，以 `account_no` 為準。資金進入證券帳戶後，可以換匯並分別交易美股和港股。
  </Accordion>
</AccordionGroup>
