Whale Docs 術語的唯一權威來源。產品文件連結到本頁，不重複定義這些術語。

## 產品

| 術語 | 定義 |
| --- | --- |
| **Whale** | Longport Whale SaaS 證券業務系統解決方案；本文件統一簡稱 Whale 。 |
| **Whale Docs** | Longport Whale 的統一文件門戶。它是門戶，不是 API 產品。 |
| **WhaleSDK** | Whale 的客戶端 SDK 產品族總稱，包含圖形介面 SDK WhaleAppSDK 和無 UI 資料 SDK WhaleCoreSDK。 |
| **WhaleAppSDK** | WhaleSDK 中提供完整證券業務圖形介面的 SDK，包含 iOS、Android 與 WebTrade 三種形態。 |
| **WhaleCoreSDK** | WhaleSDK 中不含 UI 的資料 SDK。面向 iOS、Android、Web 三個平臺；iOS、Android 已可用，Web 的 WebAssembly 版本開發中。提供行情訂閱、WebSocket、認證簽名和 token 續期等基礎機制。 |
| **WebTrade** | WhaleAppSDK 中面向 Web 頁面、iframe 或 WebView 容器的圖形介面交付形態。 |
| **BrokerAPI** | 面向 Broker 的機構級 API，支援 Server-to-Server 整合，也可為 Broker 自研管理後臺提供資料與 SaaS 櫃檯能力；實際請求由 Broker 控制的服務端發起。 |
| **TradingAPI** | 供 Broker App 使用的 Customer 級 HTTP API，通常與 WhaleCoreSDK 配合，用於完全自行實現證券功能 UI。 |
| **OpenAPI** | 面向 Broker 的 Customer 的開放能力。用於策略交易、量化分析和開發者工具，並透過 MCP 等 AI-native 方式讓 Customer 授權 AI 接入其帳戶、資產、行情和基本面資料。 |

## 參與方與角色

| 術語 | 定義 |
| --- | --- |
| **Broker** | 接入 Whale 的機構，負責自己的產品、Customer 服務及專案上線，也是 BrokerAPI 的授權邊界。 |
| **Customer** | Broker 服務的終端客戶，是 WhaleAppSDK、WhaleCoreSDK、TradingAPI 與 OpenAPI 的客戶級身份。 |
| **Broker Developer** | 代表 Broker 建設 Broker Server 整合或 Broker App 的開發人員。 |
| **Broker App Developer** | 代表 Broker 開發 iOS、Android、桌面或 Web Broker App 的開發人員。 |
| **Developer Customer** | 使用 OpenAPI 開發策略交易、量化分析、開發者工具或 AI 應用的 Broker Customer。 |

## 授權

| 術語 | 定義 |
| --- | --- |
| **Broker-scoped Authorization（機構級授權）** | Broker 機構級訪問許可權，可按獲批能力訪問該 Broker 範圍內的資料。 |
| **Customer-scoped Authorization（客戶級授權）** | 由單個客戶授予的訪問許可權，只覆蓋該客戶的私有資料和平臺公開資料。 |

## 標的標識

同一個標的在 Whale 中有兩種標識格式：`counter_id` 用於系統內部，`symbol` 用於 OpenAPI。`counter_id` 可單向轉換為 `symbol`，反之則不行。

### counter_id

`counter_id` 是 Longport Whale 系統內部通用的標的標識，幾乎所有內部 API 與場景中出現的 `counter_id` 含義都一致。格式為 `{TYPE}/{MARKET}/{CODE}`。

| 段 | 含義 | 說明 |
| --- | --- | --- |
| `TYPE` | 標的類型 | 見下表；解析時統一轉為大寫 |
| `MARKET` | 市場 | 如 `US`、`HK`、`SH`、`SZ`、`SG`、`JP`；解析時統一轉為大寫 |
| `CODE` | 標的代碼 | 大小寫敏感，保留原始寫法 |

`TYPE` 取值：

| TYPE | 含義 |
| --- | --- |
| `ST` | 股票 |
| `ETF` | 場內基金 |
| `UT` | 場外基金（貨幣型除外） |
| `MMF` | 貨幣基金 |
| `WT` | 輪證 |
| `IX` | 市場指數 |
| `BK` | 板塊 / 自定義指數 |
| `OP` | 期權（僅美股） |
| `DLC` | 新加坡每日槓桿證書 |
| `VA` | 虛擬貨幣 |
| `PE` | 私募基金 |
| `LB` | 未上市公司 |
| `TN` | 私有標的（無行情） |
| `DP` | 財富衍生產品 |

示例：

- `ST/US/NVDA` — 美股輝達
- `ST/HK/700` — 港股騰訊
- `ST/SZ/11245`、`ST/SH/076251` — A 股（`SH`、`SZ` 歸屬地區為 `CN`）
- `ST/SG/D05` — 新加坡股
- `OP/US/BILI/220304C30500` — 美股期權（`CODE` 段可包含額外的 `/`）

注意：

- `CODE` 大小寫敏感；`TYPE` 與 `MARKET` 會在解析時轉為大寫。
- 港股數字代碼在顯示時補零到 5 位（如 `00700`），但 `counter_id` 字串本身使用原始代碼（如 `700`）。

### symbol

`symbol` 一般用於 OpenAPI，格式為 `{CODE}.{MARKET}`，例如 `TSLA.US`、`700.HK`。

<Note>
轉換是單向的：將 `counter_id` 去掉 `TYPE` 段、重排為 `{CODE}.{MARKET}` 即可得到 `symbol`（如 `ST/HK/700` → `700.HK`）。反過來不行——`symbol` 不含 `TYPE`，無法直接還原出 `counter_id`。
</Note>
