## Delivery and compatibility

<AccordionGroup>
  <Accordion title="How is the SDK delivered? Is source included?">Android uses an `.aar`; iOS uses an `.xcframework`. Both are binary packages without source code.</Accordion>
  <Accordion title="Does it support dynamic delivery or hot updates?">No. An update requires a new Broker App release. Integration builds may be frequent; after launch, features follow an agreed cadence and urgent defects are prioritized. The current and next development versions are typically maintained in parallel.</Accordion>
  <Accordion title="How much package size does it add?">A reference build added about 80 MB on Android and 90 MB on iOS. More than 20 MB can be an optional H5 offline bundle; excluding it slows H5 pages until it downloads after startup. Actual size varies by build.</Accordion>
  <Accordion title="How are dependency conflicts and licenses handled?">Conflict-prone libraries are isolated or customized. Use the bundled version or exclude a transitive dependency as documented in the [Android guide](/en/whalesdk/android). The full dependency, version, and license inventory is supplied during formal integration.</Accordion>
  <Accordion title="Are APIs backward-compatible?">Existing APIs remain compatible wherever possible. Unavoidable breaking changes are identified in release notes.</Accordion>
</AccordionGroup>

## Historical performance reference

| Stage | Android | iOS |
| --- | ---: | ---: |
| Before / after SDK start | 274 / 350 MB | 11 / 58 MB |

An iOS 4.68.0 sample reported average CPU 22.4%, median CPU 20.9%, average 58.4 FPS, average/median request latency 152/91.1 ms, and average request size 12.2 KB. Android profiling is supplied during integration.
