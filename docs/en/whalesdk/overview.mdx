**WhaleSDK** is the umbrella name for Whale client SDK products. Broker selects a specific product based on whether a ready-made UI is required and which platform it targets.

| Product           | UI                     | Platforms                                             | Best fit                                                                  |
| ----------------- | ---------------------- | ----------------------------------------------------- | ------------------------------------------------------------------------- |
| **WhaleAppSDK**  | Complete securities UI | iOS, Android, WebTrade                                | Integrate a graphical experience in Broker App, website, or web container |
| **WhaleCore**    | No UI                  | iOS, Android, Web (WebAssembly), Flutter              | Implement the complete securities UI in Broker App                        |

## WhaleAppSDK {/* whaleappsdk */}

WhaleAppSDK supplies the implemented securities UI and business functionality in three form factors:

- [WhaleAppSDK for iOS](/en/whalesdk/whaleapp/ios)
- [WhaleAppSDK for Android](/en/whalesdk/whaleapp/android)
- [WhaleAppSDK WebTrade](/en/whalesdk/whaleapp/web)
- [Product capabilities and example screens](/en/whalesdk/whaleapp/capabilities)
- [Technical FAQ and reference performance data](/en/whalesdk/whaleapp/faq)
- [Shared mobile integration flow](/en/whalesdk/whaleapp/overview)

Broker App must also integrate system notifications and pass the standard message body to WhaleAppSDK. See [Message-push integration](/en/docs/message-push) for server channels, cloud credentials, and client responsibilities.

### WebTrade {/* webtrade */}

WebTrade is the web trading client form factor of WhaleAppSDK, equivalent to the web version of the iOS/Android App. It supports two integration forms: opening in a new tab (`sdk.open()`) or embedding in a Broker website via iframe (`sdk.embed()`); both forms complete SSO and preference sync through the WhaleAppSDK JavaScript library, and the iframe form also supports event callbacks and request/response.

## WhaleCore {/* whalecore */}

WhaleCore is the UI-free data SDK in WhaleSDK. It provides market-data subscriptions, WebSocket connectivity, request signing, and automatic token renewal. A Broker App combines WhaleCore with TradingAPI to implement its complete securities UI and business flow.

Start with the [WhaleCore overview](/en/whalesdk/whalecore/overview), then follow the [iOS](/en/whalesdk/whalecore/ios), [Android](/en/whalesdk/whalecore/android), [TypeScript](/en/whalesdk/whalecore/typescript), or [Flutter](/en/whalesdk/whalecore/flutter) guide.
