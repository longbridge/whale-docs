Longport Whale is a SaaS securities business solution for brokers. Whale Docs is its unified documentation portal, covering the product itself, back-office operations, implementation, and three API integration paths.

## Products

<CardGroup cols={2}>
  <Card title="WhaleSDK" icon="smartphone" href="/en/whalesdk/overview">
    Whale client SDK products: graphical WhaleAppSDK (iOS, Android, and WebTrade) and UI-free WhaleCoreSDK.
  </Card>
  <Card title="BrokerAPI" icon="server" href="/en/broker-api/overview">
    Institution-grade API for Server-to-Server integration or a Broker's self-built administration system, with Broker-scoped data and SaaS back-office capabilities.
  </Card>
  <Card title="TradingAPI" icon="chart-candlestick" href="/en/trading-api/overview">
    Pair the UI-free WhaleCoreSDK with customer-scoped HTTP APIs when the Broker builds the securities UI in its Broker App from scratch.
  </Card>
  <Card title="OpenAPI" icon="plug" href="https://open.longportapp.com">
    For Broker Customers building algorithmic trading, quantitative analysis, and AI applications, including AI-native MCP access to accounts, assets, quotes, and fundamentals.
  </Card>
</CardGroup>

## Find your entry point

| You are | Primary task | Start here |
| --- | --- | --- |
| Broker decision maker / product owner | Understand Whale capabilities, scope, and go-live process | This section (Docs) |
| Broker implementation team | Understand business flows, prepare data, complete acceptance | This section (Docs) |
| Broker app development team | Integrate WhaleAppSDK or WhaleCoreSDK | [WhaleSDK](/en/whalesdk/overview) |
| Broker Developer | Build a Server-to-Server integration or a self-built Broker administration system | [BrokerAPI](/en/broker-api/overview) |
| Broker App Developer | Build a fully custom trading UI with WhaleCoreSDK and TradingAPI | [TradingAPI and WhaleCoreSDK](/en/trading-api/overview) |
| Developer Customer / AI user | Build strategies and quantitative tools, or authorize AI to access your own account and market data | [OpenAPI](https://open.longportapp.com) |
