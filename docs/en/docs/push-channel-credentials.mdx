This form collects the Android vendor-channel and iOS APNs details needed for Whale-managed push in UAT and production.

<Warning>
This page defines the fields to collect; do not fill real secrets into a normal document. Certificates, passwords, Client Secrets, and service-account keys must travel through an approved secret-delivery channel with environment, custodian, expiry, and rotation details.
</Warning>

## Completion rules {/* completion-rules */}

1. Confirm App identifiers and channel configuration separately for production and UAT.
2. If both Android environments use the same Package Name, fill production only and enter “None” for UAT.
3. Enter “None” for every unused push channel; do not leave it blank.
4. Choose either `.p12` or `.p8` for iOS and delete the unused credential column.
5. Record expiry and the Broker contact responsible for rotation for every credential.
