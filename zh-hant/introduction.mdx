Whale API 為 SaaS 租戶提供以程式化方式接入 Longbridge Whale 證券交易平台的能力。本參考文件當前覆蓋資產域接口，後續將持續擴充。

## 接口地址（Base URL）

```text
https://openapi.longbridge.com
```

接口目前位於 `/v1/portfolio` 與 `/data_porter` 路徑前綴下。

## 開始之前

1. 取得租戶憑證（`APP_KEY`、`ACCESS_TOKEN`、`SECRET`），由 Longbridge Whale 按租戶簽發。
2. 閱讀[鑑權簽名](/zh-hant/essentials/authentication)，了解請求簽名機制。
3. 查看[透傳請求標頭](/zh-hant/essentials/passthrough-headers)，了解語言與平台相關的請求標頭。

<Note>
官方 SDK 已內建請求簽名邏輯。僅在直接調用 HTTP API 時才需要自行實現簽名。
</Note>
