Whale API 為 SaaS 租戶提供以程式化方式接入 Longbridge Whale 證券交易平台的能力，涵蓋賬戶、資產、交易、新股認購（IPO）、出入金及股票轉倉等核心業務。

## 接口地址（Base URL）

```text
https://openapi.longbridge.com
```

所有接口均位於 `/v1/whaleapi` 路徑前綴下（少數接口使用 `/v2` 或 `/v3`）。

## 開始之前

1. 取得租戶憑證（`APP_KEY`、`ACCESS_TOKEN`、`SECRET`）—— Access Key 的管理接口參見 OpenAPI 分組。
2. 閱讀[鑑權簽名](/zh-hant/essentials/authentication)，了解請求簽名機制。
3. 查看[透傳請求標頭](/zh-hant/essentials/passthrough-headers)，了解語言與平台相關的請求標頭。

<Note>
官方 SDK 已內建請求簽名邏輯。僅在直接調用 HTTP API 時才需要自行實現簽名。
</Note>
