Trading API 是供券商自研客戶端接入的客戶級 API。每個請求以單個客戶身份授權，只能訪問該客戶的資料及平台公開內容。

<Note>
Trading API 計劃於 2026 年第四季度啟動建設，本欄目將隨產品建設逐步完善。
</Note>

## 可以期待的能力

- 客戶級授權 —— 每個終端客戶一個 access token
- 面向客戶端場景的交易、行情、資產與賬戶接口
- 與 [Broker API](/zh-hant/broker-api/get-started/authentication) 一致的鑑權方案

在此之前，可先查閱 [Broker API 參考](/zh-hant/api-reference/data-porter/account-cash-balances)完成機構級對接。
