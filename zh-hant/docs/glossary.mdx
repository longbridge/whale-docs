Whale Docs 術語的唯一權威來源。產品文件連結到本頁，不重複定義這些術語。

## 產品

| 術語 | 定義 |
| --- | --- |
| **Longport Whale** | 面向券商的 SaaS 證券業務系統解決方案；本門戶所描述的產品主體。 |
| **Whale Docs** | Longport Whale 的統一文件門戶。它是門戶，不是 API 產品。 |
| **Whale Console** | 供券商櫃台操作人員使用的後台產品，以及該產品對應的操作手冊與任務指引欄目。 |
| **WhaleSDK** | 將完整客戶交易體驗嵌入券商自有客戶端的集成產品，包含 iOS、Android 和 WebTrade 三種形態。 |
| **WebTrade** | WhaleSDK 面向 Web 或 Web 容器宿主的交付形態，與 iOS、Android 並列。 |
| **Broker API** | 供券商後端以 Server-to-Server 方式調用的機構級 API，授權範圍可覆蓋該券商下的資料與 SaaS 櫃台能力。 |
| **Trading API** | 供券商自研客戶端接入的客戶級 API，以單個客戶身份授權。計劃 2026 年第四季度啟動建設。 |
| **OpenAPI** | 供券商的開發者客戶及 AI 應用使用的客戶級開放 API。 |

## 參與方與角色

| 術語 | 定義 |
| --- | --- |
| **Broker（券商）** | 採購並運營 Longport Whale 的持牌券商機構，也是 Broker API 的授權邊界。 |
| **Customer（客戶）** | 券商服務的終端客戶，是 Trading API 與 OpenAPI 的授權邊界。 |
| **Broker Developer** | 代表券商建設服務端集成或自研客戶端的開發人員。 |
| **Broker App Developer** | 代表券商將 WhaleSDK 集成到 iOS、Android 或 Web 容器的客戶端開發人員。 |
| **Broker Operator** | 在 Whale Console 執行日常櫃台業務、審核、配置、查詢和異常處理的操作人員。 |
| **Developer Customer** | 使用 OpenAPI 構建個人、第三方或 AI 應用的券商客戶。 |

## 授權

| 術語 | 定義 |
| --- | --- |
| **Broker-scoped Authorization（機構級授權）** | 由券商授予的機構級訪問權限，可按獲批能力訪問該券商範圍內的資料。 |
| **Customer-scoped Authorization（客戶級授權）** | 由單個客戶授予的訪問權限，只覆蓋該客戶的私有資料和平台公開資料。 |
