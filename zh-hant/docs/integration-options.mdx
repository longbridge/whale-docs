description: 按調用方與授權主體選擇正確的接入路徑
---

Longport Whale 提供一個嵌入式客戶端產品和三種 API。選哪個取決於**誰在調用**，以及**調用被授權訪問誰的資料**。

## 對比

| 產品 | 調用方 | 授權主體 | 私有資料範圍 | 形態 | 狀態 |
| --- | --- | --- | --- | --- | --- |
| [Whale Console](/zh-hant/whale-console/overview) | 券商櫃台操作人員 | Broker 操作員 | 按角色和權限可見的機構業務資料 | 後台操作界面 | 規劃中 |
| [WhaleSDK](/zh-hant/whalesdk/overview) | 券商 App 開發團隊 | 待確認 | 待確認 | iOS / Android / WebTrade | 已有產品；文件待納入 |
| [Broker API](/zh-hant/broker-api/overview) | 券商後端服務 | **Broker** | 獲批的機構範圍 | Server-to-Server | 可用 |
| [Trading API](/zh-hant/trading-api/introduction) | 券商自研客戶端 | **Customer** | 單個客戶 | 客戶端 API | 計劃 2026 Q4 啟動 |
| [OpenAPI ↗](https://open.longportapp.com) | 開發者客戶、AI 應用 | **Customer** | 單個客戶 | 開放平台 API / SDK | 可用（外部站點） |

## 如何選擇

- **嵌入式體驗 vs 自研客戶端** —— 想在自有 App 裡放一套現成的完整交易 UI，用 **WhaleSDK**；要自己做客戶端 UI，等 **Trading API**。
- **機構授權 vs 客戶授權** —— 以券商機構身份運行的後端集成用 **Broker API**；以單個終端客戶身份運行的一律屬於 **Trading API** 或 **OpenAPI**。
- **券商開發者 vs 開發者客戶** —— 前者代表券商，後者是券商服務的客戶。即使兩者調用相似的行情或交易能力，也不共享授權模型。

<Note>
平台公開內容（行情、基本面、資訊）仍歸屬提供它的 API 產品 —— 「公開」不代表無需認證。
</Note>
