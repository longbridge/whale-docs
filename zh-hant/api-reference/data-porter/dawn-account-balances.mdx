---
title: "現金賬戶餘額"
description: "templateId: dawn_account_balances"
api: "GET https://openapi.longbridge.com/data_porter/template/data"
---

透過 data porter 多場景查詢接口查詢現金賬戶餘額列表。`data_porter` 按 `template_id` 區分業務場景，不同模板的篩選條件與返回結構不同 —— 本頁對應 `dawn_account_balances` 模板。

返回 `book_balance <> 0` 或 `unavailable_amount <> 0` 的記錄，按 `id` 倒序。分頁規格：每頁 10 / 20 / 50 / 100 / 200 條（預設 10）。

## 請求參數

<ParamField query="template_id" type="string" required default="dawn_account_balances">
  模板 ID，本數據集固定為 `dawn_account_balances`。
</ParamField>

<ParamField query="aaid" type="string">
  客戶標識（AAID）。傳入 `member_id` 時內部會轉換為 AAID。
</ParamField>

<ParamField query="member_id" type="string">
  客戶編號，與 `aaid` 二選一。
</ParamField>

<ParamField query="origin_id" type="string">
  證券賬號（A/C No）。
</ParamField>

<ParamField query="currency" type="string">
  幣種篩選。選項按租戶下發（ref: `global_currency_filter_by_account_channel`）。
</ParamField>

<ParamField query="account_type" type="string" default="SETTLEMENT">
  賬戶類型篩選（ref: `account_type`）。
</ParamField>

<ParamField query="updated_at" type="string">
  更新時間區間篩選。
</ParamField>

<ParamField query="account_channel" type="string">
  櫃枱渠道。
</ParamField>

## 回應

<ResponseField name="items" type="array">
  結果行列表。

  <Expandable title="行欄位">
    <ResponseField name="id" type="integer">編號。</ResponseField>
    <ResponseField name="member_id" type="string">客戶編號。</ResponseField>
    <ResponseField name="real_name" type="string">客戶姓名（關聯客戶信息表）。</ResponseField>
    <ResponseField name="aaid" type="string">AAID（關聯客戶信息表）。</ResponseField>
    <ResponseField name="origin_id" type="string">證券賬號（A/C No）。</ResponseField>
    <ResponseField name="account_type" type="string">賬戶類型。</ResponseField>
    <ResponseField name="currency" type="string">幣種。</ResponseField>
    <ResponseField name="custom_unavailable_amount" type="string">凍結資金。金額，格式 `%###.2f`。</ResponseField>
    <ResponseField name="book_balance" type="string">總餘額。金額，格式 `%###.2f`。</ResponseField>
    <ResponseField name="updated_at" type="string">更新時間（時間戳）。</ResponseField>
  </Expandable>
</ResponseField>
