Broker API 是供券商後端服務以 Server-to-Server 方式調用的機構級 API。以**券商機構**為授權主體 —— 一份憑證覆蓋機構獲批範圍內的資料與 SaaS 櫃台能力。

## 一覽

| | |
| --- | --- |
| 調用方 | 券商後端服務 |
| 授權主體 | Broker（**機構級授權 / Broker-scoped Authorization**） |
| 私有資料範圍 | 獲批的機構範圍 |
| 形態 | Server-to-Server（HTTPS） |

## 不適用於

- 以單個終端客戶身份調用 —— 請使用 [Trading API](/zh-hant/trading-api/introduction)（規劃中）或 [OpenAPI ↗](https://open.longportapp.com)
- 嵌入客戶端交易 UI —— 請使用 [WhaleSDK](/zh-hant/whalesdk/overview)

## 環境

| 環境 | 網域 |
| --- | --- |
