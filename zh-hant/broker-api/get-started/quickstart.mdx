## 1. 準備憑證

你需要為券商機構簽發的一項憑證：

| 憑證 | 請求標頭 | 說明 |
| --- | --- | --- |
| `ACCESS_TOKEN` | `Authorization` | 由 Longport Whale 簽發的機構級訪問令牌 |

## 2. 發起第一個請求

以下範例查詢 `fd_organizations` 資料集（`POST /v1/datasets/fd_organizations`）：

```bash cURL
curl --request POST \
  --url https://b-api.longbridge.xyz/v1/datasets/fd_organizations \
  --header "Authorization: ${ACCESS_TOKEN}" \
  --header "Content-Type: application/json; charset=utf-8" \
  --data '{"body": {}, "page": 1, "page_size": 20}'
```

```python Python
import requests

ACCESS_TOKEN = "${access_token}"

host = "https://b-api.longbridge.xyz"  # 生產環境：https://b-api.lbkrs.com
uri = "/v1/datasets/fd_organizations"

resp = requests.post(
    url=host + uri,
    headers={
        "Authorization": ACCESS_TOKEN,
        "Content-Type": "application/json; charset=utf-8",
    },
    json={"body": {}, "page": 1, "page_size": 20},
)
print(resp.json())
```

<Tip>
切換測試 / 生產環境只需修改 `host` —— 測試環境 `https://b-api.longbridge.xyz` 不會影響真實資料。
</Tip>
