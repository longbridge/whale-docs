## 資料集查詢遷移至 `POST /v1/datasets/<name>`

### Broker API

資料集查詢從原先的單一多用途端點改為按資料集獨立路徑。資料集名位於 URL 中，請求體只攜帶過濾條件與分頁。

```json
POST /v1/datasets/account_cash_balances
{ "body": {}, "page": 1, "page_size": 20 }
```

### 影響範圍

- `POST /v1/datasets/<name>` —— 每個資料集一條 operation，共 355 個資料集
</Update>

<Update label="2026 年 7 月" tags={["變更"]}>
## 鑑權簡化為單一請求標頭

### Broker API

請求改為在 `Authorization` 請求標頭中攜帶機構級 `ACCESS_TOKEN` 完成鑑權。原 HMAC-SHA256 簽名方案（`X-Api-Key`、`X-Timestamp`、`X-Api-Signature`）不再需要。

### 影響範圍

- 全部 Broker API 接口
</Update>
