WhaleSDK 交付已經實現的客戶端交易 UI 與完整業務功能。券商主要完成宿主集成、身份銜接、品牌配置和發布 —— 不需要重新實現交易功能。

它提供三種交付形態：

- **iOS** —— 面向券商 iOS 客戶端的原生交付形態
- **Android** —— 面向券商 Android 客戶端的原生交付形態
- **WebTrade** —— 面向 Web 或 Web 容器宿主的交付形態

<Note>
本欄目建設中。現有的 iOS / Android / WebTrade 材料正在盤點納入；共享集成內容（身份銜接、品牌配置、生命週期、發布）只定義一次，平台頁只承載差異。
</Note>

## 責任邊界

WhaleSDK 的每個頁面都會區分：

- **由 WhaleSDK 完整提供** —— 交易 UI 與業務功能
- **宿主 App 的集成責任** —— 集成、身份 / 會話銜接、原生權限、發布
