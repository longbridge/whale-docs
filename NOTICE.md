# Third-party design references

Whale Docs uses Astro and Starlight. Its custom theme implementation was
informed by reusable interaction and layout patterns in Cloudflare Docs'
open-source Nimbus theme, including product-level navigation, fixed document
sidebars, horizontally scrollable tables, image zoom, and return-to-top
behavior.

Cloudflare Docs code is available from
<https://github.com/cloudflare/cloudflare-docs> under the MIT License. No
Cloudflare branding or documentation content is included in Whale Docs.

Whale colors, logos, typography choices, navigation labels, content, and the
Mintlify-compatible visual treatment are maintained independently in this
repository.
