# Third-party design references

Whale Docs uses Astro and includes adapted source from Cloudflare Docs'
open-source Nimbus implementation.

Cloudflare Docs code is available from
<https://github.com/cloudflare/cloudflare-docs>. The vendored baseline is pinned
to commit `292a11c752b29f130ed1c0811fd874b55567ae26` and is licensed under the
[Creative Commons Attribution 4.0 International License](https://creativecommons.org/licenses/by/4.0/).
It has been adapted to use Whale branding; Cloudflare product content and
branding are not included.

Reusable alert structure and component-state conventions are adapted from the
MIT-licensed ReUI registry at <https://github.com/keenthemes/reui>. Icons are
provided by Lucide through `lucide-astro`.

Whale colors, logos, typography choices, navigation labels, content, and visual
treatment are maintained independently in this repository.
