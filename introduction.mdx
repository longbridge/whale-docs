Whale API provides SaaS tenants with programmatic access to the Longbridge Whale brokerage platform — accounts, assets, trading, IPO subscription, cash and stock transfers, and more.

## Base URL

```text
https://openapi.longbridge.com
```

All endpoints are served under the `/v1/whaleapi` prefix (a few endpoints use `/v2` or `/v3`).

## Before You Start

1. Obtain your tenant credentials (`APP_KEY`, `ACCESS_TOKEN`, `SECRET`) — see the OpenAPI section for Access Key management endpoints.
2. Read the [Authentication](/essentials/authentication) guide to understand request signing.
3. Review [Passthrough Headers](/essentials/passthrough-headers) for locale and platform headers.

<Note>
Official SDKs implement request signing for you. Manual signing is only required when calling the HTTP API directly.
</Note>
