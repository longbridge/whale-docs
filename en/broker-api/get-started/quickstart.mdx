## 1. Prepare credentials

You need one credential issued for your broker:

| Credential | Header | Description |
| --- | --- | --- |
| `ACCESS_TOKEN` | `Authorization` | Broker-scoped access token issued by Longport Whale |

## 2. Send your first request

The example below queries the `fd_organizations` dataset (`POST /v1/datasets/fd_organizations`):

```bash cURL
curl --request POST \
  --url https://b-api.longbridge.xyz/v1/datasets/fd_organizations \
  --header "Authorization: ${ACCESS_TOKEN}" \
  --header "Content-Type: application/json; charset=utf-8" \
  --data '{"body": {}, "page": 1, "page_size": 20}'
```

```python Python
import requests

ACCESS_TOKEN = "${access_token}"

host = "https://b-api.longbridge.xyz"  # production: https://b-api.lbkrs.com
uri = "/v1/datasets/fd_organizations"

resp = requests.post(
    url=host + uri,
    headers={
        "Authorization": ACCESS_TOKEN,
        "Content-Type": "application/json; charset=utf-8",
    },
    json={"body": {}, "page": 1, "page_size": 20},
)
print(resp.json())
```

<Tip>
Switch between Test and Production environments by changing the `host` — use `https://b-api.longbridge.xyz` for testing without affecting live data.
</Tip>
