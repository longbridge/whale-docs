Broker API is the institution-grade API for broker backend services, called server-to-server. It is authorized at the **broker** level — one credential covers the approved scope of your organization's data and SaaS back-office capabilities.

## At a glance

| | |
| --- | --- |
| Caller | Broker backend services |
| Authorization subject | Broker (**Broker-scoped Authorization**) |
| Private data scope | Approved broker-wide scope |
| Form | Server-to-Server over HTTPS |

## Not for

- Acting as a single end customer — use [Trading API](/en/trading-api/introduction) (planned) or [OpenAPI ↗](https://open.longportapp.com) instead
- Embedding a client trading UI — use [Whale SDK](/en/whalesdk/overview)
