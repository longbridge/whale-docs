Queries cash account balance rows via the data porter multi-purpose query interface. `data_porter` serves different business datasets depending on `template_id` — this page documents the `dawn_account_balances` template.

Returns rows where `book_balance <> 0` or `unavailable_amount <> 0`, ordered by `id` descending. Pagination: 10 / 20 / 50 / 100 / 200 per page (default 10).

## Query Parameters

<ParamField query="template_id" type="string" required default="dawn_account_balances">
  Template ID. Fixed value `dawn_account_balances` for this dataset.
</ParamField>

<ParamField query="aaid" type="string">
  Client identifier (AAID). A `member_id` is resolved to AAID internally.
</ParamField>

<ParamField query="member_id" type="string">
  Member ID. Alternative to `aaid`.
</ParamField>

<ParamField query="origin_id" type="string">
  Securities account number (A/C No).
</ParamField>

<ParamField query="currency" type="string">
  Currency filter. Options are tenant-scoped (ref: `global_currency_filter_by_account_channel`).
</ParamField>

<ParamField query="account_type" type="string" default="SETTLEMENT">
  Account type filter (ref: `account_type`).
</ParamField>

<ParamField query="updated_at" type="string">
  Updated-at date range filter.
</ParamField>

<ParamField query="account_channel" type="string">
  Tenant counter channel.
</ParamField>
