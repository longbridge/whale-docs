<Note>
This page grows as recurring questions come in from brokers and developers.
</Note>

<AccordionGroup>
  <Accordion title="Which API should I integrate with?">
    It depends on who is calling and whose data is accessed. See [Integration Options](/en/docs/integration-options) — the one-table answer.
  </Accordion>
  <Accordion title="How do I get Broker API credentials?">
    The broker-scoped `ACCESS_TOKEN` is issued per broker by Longport Whale. See [Authentication](/en/broker-api/get-started/authentication).
  </Accordion>
  <Accordion title="Is there a test environment?">
    Yes — `https://b-api.longbridge.xyz`. The API playground defaults to it, so you can try requests without touching production data.
  </Accordion>
</AccordionGroup>
