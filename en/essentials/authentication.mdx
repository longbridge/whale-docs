title: Authentication
description: Request signing with HMAC-SHA256
---

Whale API authenticates every request with an HMAC-SHA256 signature.

<Note>
SDK users can skip this page — official SDKs implement the signing logic. This reference is for calling the HTTP API directly.
</Note>

## Required headers

| Header | Value | Example |
| --- | --- | --- |
| `X-Api-Key` | `APP_KEY` | `${app_key}` |
| `Authorization` | `ACCESS_TOKEN` | `${access_token}` |
| `X-Timestamp` | Unix timestamp | `1539095200.123` |
| `Content-Type` | Content type | `application/json; charset=utf-8` |
| `X-Api-Signature` | Computed signature | see below |

## Signing algorithm

<Steps>
  <Step title="Construct the canonical request">
    ```text
    canonical_request = METHOD + "|" + URI + "|" + PARAMS
        + "|authorization:" + access_token
        + "\nx-api-key:" + app_key
        + "\nx-timestamp:" + ts
        + "\n|authorization;x-api-key;x-timestamp|"
    ```

    - `METHOD` — HTTP method in uppercase, e.g. `POST`
    - `URI` — request path, e.g. `/v1/whaleapi/account/get`
    - `PARAMS` — query string, e.g. `member_id=1&account_channel=2` (empty string when absent)

    If the request has a body, append its SHA1 hash:

    ```text
    canonical_request += SHA1(body)
    ```
  </Step>
  <Step title="Build the string to sign">
    ```text
    sign_str = "HMAC-SHA256|" + SHA1(canonical_request)
    ```
  </Step>
  <Step title="Compute the signature">
    ```text
    signature = HMAC-SHA256(secret, sign_str)
    ```
  </Step>
  <Step title="Set the header">
    ```text
    X-Api-Signature: HMAC-SHA256 SignedHeaders=authorization;x-api-key;x-timestamp, Signature={signature}
    ```
  </Step>
</Steps>

## Reference implementation

```python Python
import json, time, hashlib, hmac

def sign(method, uri, headers, params, body, secret):
    ts = headers["X-Timestamp"]
    access_token = headers["Authorization"]
    app_key = headers["X-Api-Key"]

    canonical_request = (
        method.upper() + "|" + uri + "|" + params
        + "|authorization:" + access_token
        + "\nx-api-key:" + app_key
        + "\nx-timestamp:" + ts
        + "\n|authorization;x-api-key;x-timestamp|"
    )
    if body:
        canonical_request += hashlib.sha1(body.encode("utf-8")).hexdigest()

    sign_str = "HMAC-SHA256|" + hashlib.sha1(canonical_request.encode("utf-8")).hexdigest()
    signature = hmac.new(secret.encode("utf-8"), sign_str.encode("utf-8"),
                         digestmod=hashlib.sha256).hexdigest()
    return ("HMAC-SHA256 SignedHeaders=authorization;x-api-key;x-timestamp, "
            "Signature=" + signature)
```

## Obtaining credentials

`APP_KEY`, `ACCESS_TOKEN` and `SECRET` are issued per tenant by Longbridge Whale.
