Whale API provides SaaS tenants with programmatic access to the Longbridge Whale brokerage platform. This reference currently covers the asset domain and will expand over time.

## Base URL

```text
https://openapi.longbridge.com
```

Endpoints are currently served under the `/v1/portfolio` and `/data_porter` prefixes.

## Before You Start

1. Obtain your tenant credentials (`APP_KEY`, `ACCESS_TOKEN`, `SECRET`) — see the OpenAPI section for Access Key management endpoints.
2. Read the [Authentication](/en/essentials/authentication) guide to understand request signing.
3. Review [Passthrough Headers](/en/essentials/passthrough-headers) for locale and platform headers.

<Note>
Official SDKs implement request signing for you. Manual signing is only required when calling the HTTP API directly.
</Note>
