Whale API provides SaaS tenants with programmatic access to the Longport Whale brokerage platform. This reference currently covers the asset domain and will expand over time.

## Base URLs

| Environment | Base URL |
| --- | --- |
| Production | `https://b-api.lbkrs.com` |
| Test | `https://b-api.longbridge.xyz` |

Endpoints are grouped by business domain (Asset / Cash Management / Risk Control / …). The `data_porter/<template_id>/info` family is a multi-purpose query interface: one physical endpoint, different `template_id`s for different datasets.

## Before You Start

1. Obtain your tenant credentials (`APP_KEY`, `ACCESS_TOKEN`, `SECRET`) — see the OpenAPI section for Access Key management endpoints.
2. Read the [Authentication](/en/essentials/authentication) guide to understand request signing.
3. Review [Passthrough Headers](/en/essentials/passthrough-headers) for locale and platform headers.

<Note>
Official SDKs implement request signing for you. Manual signing is only required when calling the HTTP API directly.
</Note>
