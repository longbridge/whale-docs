Longport Whale is a SaaS securities business solution for brokers. Whale Docs is its unified documentation portal, covering the product itself, back-office operations, implementation, and three API integration paths.

## Products

<CardGroup cols={2}>
  <Card title="Whale Console" icon="monitor" href="/en/whale-console/overview">
    Back-office product for broker operators — operation manuals and task guides for daily review, configuration, and troubleshooting.
  </Card>
  <Card title="WhaleSDK" icon="smartphone" href="/en/whalesdk/overview">
    Embed the full trading experience into your own app — iOS, Android, and WebTrade form factors with ready-to-integrate UI.
  </Card>
  <Card title="Broker API" icon="server" href="/en/broker-api/overview">
    Institution-grade server-to-server API for broker backends. Broker-scoped authorization covers your data and SaaS back-office capabilities.
  </Card>
  <Card title="Trading API" icon="chart-candlestick" href="/en/trading-api/introduction">
    Customer-scoped API for brokers building their own client apps. Development planned to start in Q4 2026.
  </Card>
  <Card title="OpenAPI" icon="plug" href="https://open.longportapp.com">
    Customer-scoped open API for your developer customers and AI applications, authorized per individual customer.
  </Card>
</CardGroup>

## Find your entry point

| You are | Primary task | Start here |
| --- | --- | --- |
| Broker decision maker / product owner | Understand Whale capabilities, scope, and go-live process | This section (Docs) |
| Broker implementation team | Understand business flows, prepare data, complete acceptance | This section (Docs) |
| Broker operations team | Daily operations, review, configuration, exception handling | [Whale Console](/en/whale-console/overview) |
| Broker app development team | Embed the full trading UI into your own app or web container | [WhaleSDK](/en/whalesdk/overview) |
| Broker backend developer | Integrate SaaS back-office capabilities server-to-server | [Broker API](/en/broker-api/overview) |
| Broker client developer | Build a trading client for individual customers | [Trading API](/en/trading-api/introduction) |
| Developer customer / AI developer | Build applications under your own customer identity | [OpenAPI ↗](https://open.longportapp.com) |
