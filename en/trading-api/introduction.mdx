Trading API is the customer-scoped API for brokers building their own client applications. Each request is authorized as a single end customer and can only access that customer's data plus platform-public content.

<Note>
Trading API is under construction and planned to start development in Q4 2026. This section will be expanded as the product takes shape.
</Note>

## What to expect

- Customer-level authorization — one access token per end customer
- Trading, quotes, assets, and account endpoints tailored for client-facing apps
- Consistent authentication scheme with the [Broker API](/en/broker-api/get-started/authentication)

In the meantime, explore the [Broker API reference](/en/api-reference/data-porter/account-cash-balances) for institution-level integration.
