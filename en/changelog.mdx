<Update label="July 2026" tags={["Changed"]}>
## Dataset queries move to `POST /v1/datasets/<name>`

### Broker API

Dataset queries previously routed through a single multi-purpose endpoint now use a dedicated path per dataset. The dataset name is part of the URL; the request body carries only the filters and paging.

```json
POST /v1/datasets/account_cash_balances
{ "body": {}, "page": 1, "page_size": 20 }
```

### Affected Endpoints

- `POST /v1/datasets/<name>` — one operation per dataset, 355 datasets in total
</Update>

<Update label="July 2026" tags={["Changed"]}>
## Authentication simplified to a single header

### Broker API

Requests now authenticate with the broker-scoped `ACCESS_TOKEN` in the `Authorization` header. The previous HMAC-SHA256 signing scheme (`X-Api-Key`, `X-Timestamp`, `X-Api-Signature`) is no longer required.

### Affected Endpoints

- All Broker API endpoints
</Update>
