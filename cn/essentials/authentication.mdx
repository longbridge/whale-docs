---
title: 鉴权签名
description: 基于 HMAC-SHA256 的请求签名
---

Whale API 使用 HMAC-SHA256 签名对每个请求进行鉴权。

<Note>
SDK 用户可以跳过本页 —— 官方 SDK 已完整实现签名逻辑。本文仅供直接调用 HTTP API 的开发者参考。
</Note>

## 必需请求头

| 请求头 | 取值 | 示例 |
| --- | --- | --- |
| `X-Api-Key` | `APP_KEY` | `${app_key}` |
| `Authorization` | `ACCESS_TOKEN` | `${access_token}` |
| `X-Timestamp` | Unix 时间戳 | `1539095200.123` |
| `Content-Type` | 内容类型 | `application/json; charset=utf-8` |
| `X-Api-Signature` | 计算得到的签名 | 见下文 |

## 签名算法

<Steps>
  <Step title="构造规范化请求（Canonical Request）">
    ```text
    canonical_request = METHOD + "|" + URI + "|" + PARAMS
        + "|authorization:" + access_token
        + "\nx-api-key:" + app_key
        + "\nx-timestamp:" + ts
        + "\n|authorization;x-api-key;x-timestamp|"
    ```

    - `METHOD` —— HTTP 方法（大写），如 `POST`
    - `URI` —— 请求路径，如 `/v1/whaleapi/account/get`
    - `PARAMS` —— 查询字符串，如 `member_id=1&account_channel=2`（无参数时为空字符串）

    如果请求携带 body，追加其 SHA1 摘要：

    ```text
    canonical_request += SHA1(body)
    ```
  </Step>
  <Step title="构造待签名字符串">
    ```text
    sign_str = "HMAC-SHA256|" + SHA1(canonical_request)
    ```
  </Step>
  <Step title="计算签名">
    ```text
    signature = HMAC-SHA256(secret, sign_str)
    ```
  </Step>
  <Step title="设置请求头">
    ```text
    X-Api-Signature: HMAC-SHA256 SignedHeaders=authorization;x-api-key;x-timestamp, Signature={signature}
    ```
  </Step>
</Steps>

## 参考实现

```python Python
import json, time, hashlib, hmac

def sign(method, uri, headers, params, body, secret):
    ts = headers["X-Timestamp"]
    access_token = headers["Authorization"]
    app_key = headers["X-Api-Key"]

    canonical_request = (
        method.upper() + "|" + uri + "|" + params
        + "|authorization:" + access_token
        + "\nx-api-key:" + app_key
        + "\nx-timestamp:" + ts
        + "\n|authorization;x-api-key;x-timestamp|"
    )
    if body:
        canonical_request += hashlib.sha1(body.encode("utf-8")).hexdigest()

    sign_str = "HMAC-SHA256|" + hashlib.sha1(canonical_request.encode("utf-8")).hexdigest()
    signature = hmac.new(secret.encode("utf-8"), sign_str.encode("utf-8"),
                         digestmod=hashlib.sha256).hexdigest()
    return ("HMAC-SHA256 SignedHeaders=authorization;x-api-key;x-timestamp, "
            "Signature=" + signature)
```

## 获取凭证

`APP_KEY`、`ACCESS_TOKEN` 与 `SECRET` 按租户签发。Access Key 与访问令牌可通过 **OpenAPI** 分组下的接口进行管理（创建 / 查询 / 更新 / 禁用 / 续期）。
