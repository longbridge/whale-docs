<Note>
本页保留历史对接结论，便于实施时追溯。涉及环境地址、限频和业务规则的内容可能按项目调整，上线前应与 Whale 项目团队再次确认。
</Note>

<AccordionGroup>
  <Accordion title="提交开户申请后多久能完成？建议多久查询一次？">
    如果项目配置为无需人工审批、直接完成开户，后台仍通过异步任务处理。实际耗时取决于当前并发量，可每隔数秒查询一次。具体轮询间隔和限频需以项目配置为准。
  </Accordion>

  <Accordion title="出入金接口的 bizCode 是什么？金额如何传递？">
    业务码请参考 [Broker API 资产接口](https://apidocs.longbridgewhale.com/whaleapi/asset-348068f0)。出金和入金的金额都传正数，通过 `direction` 区分方向。
  </Accordion>

  <Accordion title="出入金金额支持多少位小数？">
    最高支持两位小数，账户中的金额也按两位小数保存。
  </Accordion>

  <Accordion title="接口错误应该看 HTTP 状态还是响应体 code？">
    历史接口在发生错误时可能返回 HTTP `400`，响应体中同时提供 `404002`、`404102` 等业务错误码；业务判断以响应体 `code` 为准。正常请求返回 HTTP `200`，响应体 `code` 为 `0`。
  </Accordion>

  <Accordion title="UAT 环境域名是什么？">
    历史材料记录的地址为 `https://api.longbridgewhale.com`。配置出网前需向 Whale 项目团队确认当前项目的实际环境地址。
  </Accordion>

  <Accordion title="调账前是否需要冻结资金？">
    不需要。直接调用调账接口，不要调用冻结资金接口；冻结接口并非为调账设计。历史实现中，调账出账不校验风控，可能发生超额出账，因此调用方必须自行控制可用金额和额度。
  </Accordion>

  <Accordion title="多个市场或上手方是否需要由 Broker 区分？">
    Broker 不需要关心后续上手方，以 `account_no` 为准。资金进入证券账户后，可以换汇并分别交易美股和港股。
  </Accordion>
</AccordionGroup>
