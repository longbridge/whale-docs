Whale Docs 术语的唯一权威来源。产品文档链接到本页，不重复定义这些术语。

## 产品

| 术语 | 定义 |
| --- | --- |
| **Whale** | Longport Whale SaaS 证券业务系统解决方案；本文档统一简称 Whale 。 |
| **Whale Docs** | Longport Whale 的统一文档门户。它是门户，不是 API 产品。 |
| **WhaleSDK** | 将完整 Customer 交易体验嵌入 Broker App 的 UI 产品，包含 iOS、Android 和 WebTrade 三种形态。 |
| **WhaleCore** | WhaleSDK 的无 UI 底层数据 SDK。面向完全自行实现证券功能 UI 的 Broker App，提供行情订阅、WebSocket、认证签名和 token 续期等基础机制；提供 iOS、Android 库，WebAssembly 版本开发中。 |
| **WebTrade** | WhaleSDK 面向 Web 页面或 WebView 容器的交付形态，与 iOS、Android 并列。 |
| **Broker API** | 供 Broker Server 以 Server-to-Server 方式调用的机构级 API，授权范围可覆盖该 Broker 下的数据与 SaaS 柜台能力。 |
| **Trading API** | 供 Broker App 使用的 Customer 级 HTTP API，通常与 WhaleCore 配合，用于完全自研证券功能 UI。 |
| **OpenAPI** | 面向 Broker 的 Customer 的开放能力。用于策略交易、量化分析和开发者工具，并通过 MCP 等 AI-native 方式让 Customer 授权 AI 接入其账户、资产、行情和基本面数据。 |

## 参与方与角色

| 术语 | 定义 |
| --- | --- |
| **Broker** | 接入 Whale 的机构，负责自己的产品、Customer 服务及项目上线，也是 Broker API 的授权边界。 |
| **Customer** | Broker 服务的终端客户，是 WhaleSDK、 WhaleCore、Trading API 与 OpenAPI 的客户级身份。 |
| **Broker Developer** | 代表 Broker 建设服务端集成或自研 App 的开发人员。 |
| **Broker App Developer** | 代表 Broker 将 WhaleSDK 集成到 iOS、Android、桌面或 Web 客户端的开发人员。 |
| **Developer Customer** | 使用 OpenAPI 开发策略交易、量化分析、开发者工具或 AI 应用的 Broker Customer。 |

## 授权

| 术语 | 定义 |
| --- | --- |
| **Broker-scoped Authorization（机构级授权）** | Broker 机构级访问权限，可按获批能力访问该 Broker 范围内的数据。 |
| **Customer-scoped Authorization（客户级授权）** | 由单个客户授予的访问权限，只覆盖该客户的私有数据和平台公开数据。 |
