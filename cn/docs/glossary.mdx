Whale Docs 术语的唯一权威来源。产品文档链接到本页，不重复定义这些术语。

## 产品

| 术语 | 定义 |
| --- | --- |
| **Longport Whale** | 面向券商的 SaaS 证券业务系统解决方案；本门户所描述的产品主体。 |
| **Whale Docs** | Longport Whale 的统一文档门户。它是门户，不是 API 产品。 |
| **WhaleSDK** | 将完整客户交易体验嵌入券商自有客户端的集成产品，包含 iOS、Android 和 WebTrade 三种形态。 |
| **WebTrade** | WhaleSDK 面向 Web 页面或 WebView 容器的交付形态，与 iOS、Android 并列。 |
| **Broker API** | 供券商后端以 Server-to-Server 方式调用的机构级 API，授权范围可覆盖该券商下的数据与 SaaS 柜台能力。 |
| **Trading API** | 供券商自研客户端接入的客户级 API，以单个客户身份授权。计划 2026 年第四季度启动建设。 |
| **OpenAPI** | 供券商的开发者客户及 AI 应用使用的客户级开放 API。 |

## 参与方与角色

| 术语 | 定义 |
| --- | --- |
| **Broker（券商）** | 采购并运营 Longport Whale 的持牌券商机构，也是 Broker API 的授权边界。 |
| **Customer（客户）** | 券商服务的终端客户，是 Trading API 与 OpenAPI 的授权边界。 |
| **Broker Developer** | 代表券商建设服务端集成或自研客户端的开发人员。 |
| **Broker App Developer** | 代表券商将 WhaleSDK 集成到 iOS、Android 或 Web 容器的客户端开发人员。 |
| **Developer Customer** | 使用 OpenAPI 构建个人、第三方或 AI 应用的券商客户。 |

## 授权

| 术语 | 定义 |
| --- | --- |
| **Broker-scoped Authorization（机构级授权）** | 由券商授予的机构级访问权限，可按获批能力访问该券商范围内的数据。 |
| **Customer-scoped Authorization（客户级授权）** | 由单个客户授予的访问权限，只覆盖该客户的私有数据和平台公开数据。 |
