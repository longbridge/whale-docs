## **接口说明**

- 用户注册 / 登录（POST /v1/whaleapi/auth/open_id/login）

    - 首次登录即注册

    - 第三方用户与平台用户关系绑定（open_id -\> member_id）

        - open_id 三方系统用户唯一标识

        - member_id Whale 系统用户唯一标识

    - SDK 登录 token 颁发

- 用户登出 (POST /v1/whaleapi/auth/session/logout)

    - 用 token 将用户登出，设置 token 无效

    - 需要两个参数：

        - `member_id` - 来自于登录接口返回的

        - `sid` - 用 JWT decode 登录接口返回的 `token` 即可获得 `sid`

- 证券账户开户

    - 提交开户资料 (POST /v2/whaleapi/account/submit_application)

    - 主动调用获取开户申请状态（/v1/whaleapi/account/get_application）/ 账户开通通知（定制化开发）



## **详细设计**

### **总体流程**



```mermaid
sequenceDiagram
    autonumber
    actor Customer as Customer（终端客户）
    participant Broker as Broker 系统
    participant API as Whale API
    participant Ops as Whale 后台开户处理
    Customer->>Broker: 注册、登录或绑定账户
    Broker->>API: POST /v1/whaleapi/auth/open_id/login
    API-->>Broker: member_id、token、refresh_token
    Broker->>API: POST /v2/whaleapi/account/submit_application
    API-->>Broker: application_id
    API->>Ops: 创建异步开户任务
    Ops->>Ops: KYC、风控及账户开通
    loop 直到成功或失败
        Broker->>API: POST /v1/whaleapi/account/get_application
        API-->>Broker: 当前状态、reason 或 account_no
    end
    Broker-->>Customer: 展示开户结果
```




### **流程说明**

#### **步骤 1：用户注册 / 登录与关系绑定**

第三方系统调用登录注册接口

|**场景**|**系统行为**|
|---|---|
|用户未注册|创建平台用户（Member）|
|用户已注册|直接登录|
|第三方首次接入|建立用户关系绑定 open_id -\> member_id|



#### **步骤 2：提交开户资料**

系统在校验开户资料通过后，将生成一条开户申请记录，并返回开户申请 ID

此时仅表示 **开户申请已提交成功**，并不代表账户已开通。



#### **步骤 3：账户开通（异步）**

- 账户开通由系统后台异步处理

- 包含证券账户创建、账户能力配置等流程

- 开通完成后，将通过约定方式通知第三方系统 （**需定制化开发**）；或者主动获取开户申请状态

#### **登出用户**

**POST /v1/whaleapi/auth/session/logout**

##### **请求字段说明**

Request

|**字段名**|**类型**|**是否必填**|**说明**|
|---|---|---|---|
|member_id|string|Y|用户编号，来自于登录接口返回。|
|sid|string|Y|Session ID <br />这个信息可以用 JWT decode (标准实现) 登录的 token 获得 sid|
