## Authentication - 认证

Broker API 通过 Access Key 进行认证，一组 AccessKey 包含：

- AccessKeyId - access key id，每次请求在 header\["x-api-key"\] 中带上

- AccessKeySecret - access key secret，用于请求的签名

- AccessKeyToken - access token



The Broker API uses Access Key for authentication, which includes the following components:

- AccessKeyId - access key id, which is included in the header\["x-api-key"\] of each request

- AccessKeySecret - access key secret, which is used for request signature

- AccessKeyToken - access token



每个请求我们都要做认证校验：

- Access key 是否存在

- 请求签名是否正确

- 请求 IP 是否为 Access Key 的白名单 IP

- Access Token 是否有效

- 请求接口是否限流



For each request, we need to perform authentication checks:

- Check if the Access Key exists

- Check if the request signature is correct

- Check if the request IP is in the Access Key's whitelist IP

- Check if the Access Token is valid

- Check if the request interface is rate limited



认证过程中涉及的 header 如下



The headers involved in the authentication process are as follows:

|Header|说明|例子|
|---|---|---|
|x-api-key|Access key id|`<access-key-id>`|
|authorization<br />|Access Token<br />|`<access-token>`|
|x-timestamp|Request timestamp|1685518362.111|
|x-api-signature|Request signature|`HMAC-SHA256 SignedHeaders=x-api-key;authorization;x-timestamp,Signature=<signature>`|

## Websocket



我们会提供 Websocket 交易网关用于订单状态变更信息的推送，Broker API 的 Websocket 交易网关和我们 [OpenAPI 的 Websocket 交易网关](https://open.longportapp.com/en/docs/socket/subscribe_trade)一致。数据交互使用的私有协议和 [OpenAPI ](https://open.longportapp.com/en/docs/socket/protocol/overview)的也一致。 Broker 通过 Broker API 提交订单，当订单状态更新时就会通过 Websocket 网关推送。

> [推送内容](https://open.longportapp.com/docs/trade/trade-definition#websocket-%E6%8E%A8%E9%80%81%E9%80%9A%E7%9F%A5)
>
>



We provide a WebSocket trading gateway to push order status change information. The Broker API's WebSocket trading gateway is consistent with our [OpenAPI WebSocket trading gateway](https://open.longportapp.com/en/docs/socket/subscribe_trade). The private protocol used for data exchange is also the same as [OpenAPI's](https://open.longportapp.com/en/docs/socket/protocol/overview). Brokers submit orders through the Broker API, and order status changes are pushed through the WebSocket gateway.

> [Push Content](https://open.longportapp.com/en/docs/trade/trade-definition#websocket-notification)
>
>





### How to establish a connection - 如何建立连接

#### Establishing a Connection - 首次建连

- 首次建立 websocket 需要调用[获取 OTP 的接口](https://open.longportapp.com/en/docs/socket-token-api)

- 建立 websocket 连接

- 使用 otp 进行 [auth 操作](https://open.longportapp.com/en/docs/socket/control-command#auth)，auth 操作后，响应会返回一个 session id，可以用于重连

- 订阅 private topic



- To establish a WebSocket connection for the first time, the [OTP acquisition API](https://open.longportapp.com/en/docs/socket-token-api) needs to be called.

- Establish the WebSocket connection.

- Use OTP for [authentication](https://open.longportapp.com/en/docs/socket/control-command#auth). After the authentication operation, the response will return a session ID, which can be used for reconnection.

- Subscribe to the private topic.



#### Reconnection - 重连

- 建立 websocket 连接

- 使用 session id 进行 [reconnect 操作](https://open.longportapp.com/en/docs/socket/control-command#reconnect)，reconnect 操作成功后，响应会包含新的 session id 用于下次重连

- 订阅 private topic



- Establish the WebSocket connection.

- Use the session ID to perform the reconnect operation. After the reconnect operation is successful, the response will contain a new session ID for the next reconnection.

- Subscribe to the private topic.



## Example In golang

> Require install golang
>
>

```go
package main

import (
        "context"
        "encoding/json"
        "fmt"
        "log"
        "net/url"
        std_http "net/http"
        "syscall"
        "time"
        "os"
        "os/signal"

        "github.com/longbridgeapp/openapi-go/config"
        "github.com/longbridgeapp/openapi-go/http"
        "github.com/longbridgeapp/openapi-go/trade"
)

var (
        accessKeyId     = ""
        accessKeySecret = ""
        accessToken     = ""

        httpAddr           = "https://openapi.longbridge.xyz"
        tradeWebsocketAddr = "wss://openapi-trade.longbridge.xyz"
)

func main() {
        // init config
        conf := &config.Config{
                AppKey:      accessKeyId,
                AppSecret:   accessKeySecret,
                AccessToken: accessToken,
                HttpURL:     httpAddr,
                TradeUrl:    tradeWebsocketAddr,
                LogLevel:    "debug",
        }

        // init go std http client
        hc := &std_http.Client{
                Transport: &std_http.Transport{
                        MaxIdleConnsPerHost: 20,
                },
                Timeout: 10 * time.Second,
        }
        conf.Client = hc

        // new trade context
        // this operation will establish websocket connection to trade gateway
        tctx, err := trade.NewFromCfg(conf)

        if err != nil {
                log.Fatal(err)
        }

        // subscribe private topic to receive order change events
        if _, err = tctx.Subscribe(context.Background(), []string{"private"}); err != nil {
                log.Fatal(err)
        }

        // register order change event callback
        tctx.OnTrade(func(ev *trade.PushEvent) {
                log.Printf("got event: %+v\n", ev.Data)
        })

        // new http client for rest api calling
        client, err := http.New(http.WithAppKey(conf.AppKey), http.WithAppSecret(conf.AppSecret), http.WithURL(conf.HttpURL), http.WithAccessToken(conf.AccessToken))

        if err != nil {
                log.Fatal(err)
        }

        // create order
        createOrder(client)

        ch := make(chan os.Signal, 1)
        signal.Notify(sch, os.Interrupt, syscall.SIGKILL)
        s := <-ch
        log.Println("exit for " + s.String())
}

func createOrder(c *http.Client) {
        doRequest(c, Request{
                Name:   "SubmitOrder",
                Method: std_http.MethodPost,
                Path:   "/v1/whaleapi/trade/order",
                Parameters: Parameters{
                        Body: map[string]interface{}{
                                "account_no":         "L6VQEU00128518",
                                "symbol":             "AAPL.US",
                                "order_type":         "MO",
                                "submitted_quantity": "100",
                                "side":               "Buy",
                                "time_in_force":      "Day",
                        },
                },
        })
}

type Request struct {
        Name       string
        Method     string
        Path       string
        Parameters Parameters
}

type Parameters struct {
        Query  map[string]string
        Header map[string]string
        Body   map[string]interface{}
}

func doRequest(c *http.Client, req Request) {
        var resp json.RawMessage

        log.Println("calling api " + req.Name)

        q := make(url.Values)

        for k, v := range req.Parameters.Query {
                q.Set(k, v)
        }

        var body interface{}

        if len(req.Parameters.Body) != 0 {
                body = req.Parameters.Body
        }

        // call api
        err := c.Call(context.Background(), req.Method, req.Path, q, body, &resp)

        if err != nil {
                log.Printf("[ERR] failed to invoke %s error: %v\n", req.Name, err)
        } else {
                log.Println(req.Name + " resp: " + string(resp))
        }

}
```

## QA

- Broker API 访问是否有 Rate Limit，限制是多少？

    - 200 次/秒，根据 API Key 来做总线制，这个数量是够的，一般达不到这么大。

- 當日成交是以收市作cut off 還是以日清流程做cut off?

    - 美股的当日时间范围是「北京时间 9:00 -- 次日 12:00」，过了12:00 会归到历史的（冬令时夏令时会有所不同的，夏令时会都早一小时哈）
