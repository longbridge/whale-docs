> 此文档列举一些对特定 Broker 公开的 SDK 接口，这些接口在 SDK 的接口文档中没有说明。
>
> 如：行为埋点数据回调 目前 蚂蚁 在使用。
>
>

## 行为埋点数据回调

Android

```kotlin
LBWhaleApp.callback = object : LBWhaleAppCallback {
    //SDK 内部埋点事件转发回调
    //eventName：事件名；properties：事件属性（org.json.JSONObject）
    override fun onLBWhaleAppAnalyticsEvent(eventName: String, properties: org.json.JSONObject) {}
}
```

iOS

```objective-c
#pragma mark - LBWhaleAppDelegate
/// 埋点事件触发回调
/// - **Parameters**:
///   - name: 事件名称
///   - properties: 事件属性
- (**void**)lbWhaleAppAnalyticsEventWithName:(NSString *)name properties:(NSDictionary *)properties;
```

- `$AppViewScreen` - 显示界面

- `$AppPageLeave` - 退出界面

- `$AppClick` - 点击

- `whale_sdk_****` 如（whale_sdk_start、whale_sdk_start_success、whale_sdk_start_callback_run 等等）这些是 Broker App 调用 SDK 接口以及 SDK 回调的埋点，这些应该在 Broker App 自己更好。

- 业务埋点，如（community_content_exposure、search_result_exposure、news_feed_exposure）有很多，都是业务数据暴光点击埋点，这些对你们没用。
