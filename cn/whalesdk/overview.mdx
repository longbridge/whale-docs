WhaleSDK 交付已经实现的客户端交易 UI 与完整业务功能。Broker 将它集成到自己的 App 中，主要负责 SDK 集成、身份衔接、品牌配置和发布 —— 不需要重新实现交易功能。

它提供三种交付形态：

- **iOS** —— 面向券商 iOS 客户端的原生交付形态
- **Android** —— 面向券商 Android 客户端的原生交付形态
- **WebTrade** —— 面向 Web 页面或 WebView 容器的交付形态

<Note>
本栏目建设中。现有的 iOS / Android / WebTrade 材料正在盘点纳入；共享集成内容（身份衔接、品牌配置、生命周期、发布）只定义一次，平台页只承载差异。
</Note>

## 责任边界

WhaleSDK 的每个页面都会区分：

- **由 WhaleSDK 完整提供** —— 交易 UI 与业务功能
- **Broker 自研 App 的责任** —— 集成 WhaleSDK、身份 / 会话衔接、原生权限、发布

这里的 **Broker 自研 App** 是指 SaaS 客户自行开发并集成 WhaleSDK 的 App，后文简称 **Broker App**。

Broker App 还需要接入系统消息通知，并把标准消息体交给 WhaleSDK。服务端渠道、云推送凭证和客户端责任见[消息推送接入](/cn/docs/message-push)。
