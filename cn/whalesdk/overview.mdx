---
title: WhaleSDK
description: 将完整交易体验嵌入自有客户端
---

WhaleSDK 交付已经实现的客户端交易 UI 与完整业务功能。券商主要完成宿主集成、身份衔接、品牌配置和发布 —— 不需要重新实现交易功能。

它提供三种交付形态：

- **iOS** —— 面向券商 iOS 客户端的原生交付形态
- **Android** —— 面向券商 Android 客户端的原生交付形态
- **WebTrade** —— 面向 Web 或 Web 容器宿主的交付形态

<Note>
本栏目建设中。现有的 iOS / Android / WebTrade 材料正在盘点纳入；共享集成内容（身份衔接、品牌配置、生命周期、发布）只定义一次，平台页只承载差异。
</Note>

## 责任边界

WhaleSDK 的每个页面都会区分：

- **由 WhaleSDK 完整提供** —— 交易 UI 与业务功能
- **宿主 App 的集成责任** —— 集成、身份 / 会话衔接、原生权限、发布
