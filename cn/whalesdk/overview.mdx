WhaleSDK 交付已经实现的客户端交易 UI 与完整业务功能。Broker 将它集成到自己的 App 中，主要负责 SDK 集成、身份衔接、品牌配置和发布 —— 不需要重新实现交易功能。

它提供三种带图形界面的交付形态：

- **iOS** —— 面向 Broker iOS App 的原生交付形态
- **Android** —— 面向 Broker Android App 的原生交付形态
- **WebTrade** —— 面向 Web 页面或 WebView 容器的交付形态

## 责任边界

WhaleSDK 的每个页面都会区分：

- **由 WhaleSDK 完整提供** —— 交易 UI 与业务功能
- **Broker App 的责任** —— 集成 WhaleSDK、身份 / 会话衔接、原生权限、发布

Broker App 还需要接入系统消息通知，并把标准消息体交给 WhaleSDK。服务端渠道、云推送凭证和客户端责任见[消息推送接入](/cn/docs/message-push)。

## 与 WhaleCore 的关系

WhaleSDK 的底层是 **WhaleCore**。WhaleCore 不含图形界面，只提供行情订阅、WebSocket、认证签名和 token 续期等基础机制。

- 希望直接集成完整 UI：使用 WhaleSDK for iOS、WhaleSDK for Android 或 WebTrade。
- Broker App 希望完全自行实现证券功能 UI：使用 [WhaleCore 与 Trading API](/cn/trading-api/introduction)。
