<Update label="2026 年 7 月" tags={["变更"]}>
## 数据集查询迁移至 `POST /v1/datasets/<name>`

### Broker API

数据集查询从原先的单一多用途端点改为按数据集独立路径。数据集名位于 URL 中，请求体只携带过滤条件与分页。

```json
POST /v1/datasets/account_cash_balances
{ "body": {}, "page": 1, "page_size": 20 }
```

### 影响范围

- `POST /v1/datasets/<name>` —— 每个数据集一条 operation，共 355 个数据集
</Update>

<Update label="2026 年 7 月" tags={["变更"]}>
## 鉴权简化为单一请求头

### Broker API

请求改为在 `Authorization` 请求头中携带机构级 `ACCESS_TOKEN` 完成鉴权。原 HMAC-SHA256 签名方案（`X-Api-Key`、`X-Timestamp`、`X-Api-Signature`）不再需要。

### 影响范围

- 全部 Broker API 接口
</Update>
