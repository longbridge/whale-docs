Trading API 是供券商自研客户端接入的客户级 API。每个请求以单个客户身份授权，只能访问该客户的数据及平台公开内容。

<Note>
Trading API 计划于 2026 年第四季度启动建设，本栏目将随产品建设逐步完善。
</Note>

## 可以期待的能力

- 客户级授权 —— 每个终端客户一个 access token
- 面向客户端场景的交易、行情、资产与账户接口
- 与 [Broker API](/cn/essentials/authentication) 一致的签名方案

在此之前，可先查阅 [Broker API 参考](/cn/api-reference/data-porter/fd-organizations)完成机构级对接。
