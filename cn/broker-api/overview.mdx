Broker API 是供券商后端服务以 Server-to-Server 方式调用的机构级 API。以**券商机构**为授权主体 —— 一份凭证覆盖机构获批范围内的数据与 SaaS 柜台能力。

## 一览

| | |
| --- | --- |
| 调用方 | 券商后端服务 |
| 授权主体 | Broker（**机构级授权 / Broker-scoped Authorization**） |
| 私有数据范围 | 获批的机构范围 |
| 形态 | Server-to-Server（HTTPS） |

## 不适用于

- Broker 使用 WhaleCore 完全自研证券功能 UI —— 请使用 [WhaleCore 与 Trading API](/cn/trading-api/introduction)
- 由 Developer Customer 构建第三方应用 —— 请使用 [OpenAPI ↗](https://open.longportapp.com)
- 嵌入客户端交易 UI —— 请使用 [WhaleSDK](/cn/whalesdk/overview)
