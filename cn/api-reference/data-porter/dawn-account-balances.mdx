---
title: "现金账户余额"
description: "templateId: dawn_account_balances"
api: "GET https://openapi.longbridge.com/data_porter/dawn_account_balances/info"
---

通过 data porter 多场景查询接口查询现金账户余额列表。`data_porter` 按 `template_id` 区分业务场景，不同模板的筛选条件与返回结构不同 —— 本页对应 `dawn_account_balances` 模板。

返回 `book_balance <> 0` 或 `unavailable_amount <> 0` 的记录，按 `id` 倒序。分页规格：每页 10 / 20 / 50 / 100 / 200 条（默认 10）。

## 请求参数

<ParamField query="aaid" type="string">
  客户标识（AAID）。传入 `member_id` 时内部会转换为 AAID。
</ParamField>

<ParamField query="member_id" type="string">
  客户编号，与 `aaid` 二选一。
</ParamField>

<ParamField query="origin_id" type="string">
  证券账号（A/C No）。
</ParamField>

<ParamField query="currency" type="string">
  币种筛选。选项按租户下发（ref: `global_currency_filter_by_account_channel`）。
</ParamField>

<ParamField query="account_type" type="string" default="SETTLEMENT">
  账户类型筛选（ref: `account_type`）。
</ParamField>

<ParamField query="updated_at" type="string">
  更新时间区间筛选。
</ParamField>

<ParamField query="account_channel" type="string">
  柜台渠道。
</ParamField>

## 响应

<ResponseField name="items" type="array">
  结果行列表。

  <Expandable title="行字段">
    <ResponseField name="id" type="integer">编号。</ResponseField>
    <ResponseField name="member_id" type="string">客户编号。</ResponseField>
    <ResponseField name="real_name" type="string">客户姓名（关联客户信息表）。</ResponseField>
    <ResponseField name="aaid" type="string">AAID（关联客户信息表）。</ResponseField>
    <ResponseField name="origin_id" type="string">证券账号（A/C No）。</ResponseField>
    <ResponseField name="account_type" type="string">账户类型。</ResponseField>
    <ResponseField name="currency" type="string">币种。</ResponseField>
    <ResponseField name="custom_unavailable_amount" type="string">冻结资金。金额，格式 `%###.2f`。</ResponseField>
    <ResponseField name="book_balance" type="string">总余额。金额，格式 `%###.2f`。</ResponseField>
    <ResponseField name="updated_at" type="string">更新时间（时间戳）。</ResponseField>
  </Expandable>
</ResponseField>
