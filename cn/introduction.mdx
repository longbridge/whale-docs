Longport Whale 是面向券商的 SaaS 证券业务系统解决方案。 Whale Docs 是它的统一文档门户，覆盖产品本身、柜台操作、实施流程与三种 API 接入方式。

## 文档中的参与方

本文档统一使用以下参与方名称：

| 名称 | 含义 |
| --- | --- |
| **Whale** | **Longport Whale**，本文档中简称 Whale 。 |
| **Broker** | 接入 Whale 的券商或机构客户，负责自己的产品、Customer 服务及项目上线。 |
| **Customer** | Broker 服务的终端客户，也是 WhaleSDK、 WhaleCore 和 Trading API 的客户级身份。 |

除历史接口名、配置键和代码字段外，后续页面均使用这三个名称描述参与方。

## 产品

<CardGroup cols={2}>
  <Card title="WhaleSDK" icon="smartphone" href="/cn/whalesdk/overview">
    将完整交易体验嵌入自有客户端 —— 提供 iOS、Android 与 WebTrade 三种形态的可直接集成 UI。
  </Card>
  <Card title="Broker API" icon="server" href="/cn/broker-api/overview">
    面向券商后端的机构级 Server-to-Server API。以券商机构为授权边界，覆盖机构数据与 SaaS 柜台能力。
  </Card>
  <Card title="Trading API" icon="chart-candlestick" href="/cn/trading-api/introduction">
    与无 UI 的 WhaleCore 配合，供 Broker 完全自研 App 界面；覆盖 App 基础机制和 Customer 级 HTTP 业务能力。
  </Card>
  <Card title="OpenAPI" icon="plug" href="https://open.longportapp.com">
    供 Broker 的 Customer 开发策略交易、量化分析和 AI 应用；支持通过 MCP 等 AI-native 方式接入账户资产、行情与基本面能力。
  </Card>
</CardGroup>

## 按角色进入

| 你是 | 首要任务 | 入口 |
| --- | --- | --- |
| 券商决策者 / 产品负责人 | 理解 Whale 能力、实施范围和上线过程 | 本栏目（Docs） |
| 券商实施团队 | 理解业务流程、准备资料、完成验收 | 本栏目（Docs） |
| Broker App 开发团队 | 将完整交易 UI 嵌入 Broker App 或 Web 容器 | [WhaleSDK](/cn/whalesdk/overview) |
| 券商后端开发者 | 以机构身份集成 SaaS 柜台能力 | [Broker API](/cn/broker-api/overview) |
| Broker App Developer | 使用 WhaleCore 与 Trading API 完全自研交易 UI | [Trading API 与 WhaleCore](/cn/trading-api/introduction) |
| Broker 的开发者 Customer / AI 用户 | 开发策略、量化分析，或授权 AI 接入自己的账户与市场数据 | [OpenAPI ↗](https://open.longportapp.com) |
