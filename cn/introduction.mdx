Longport Whale 是面向券商的 SaaS 证券业务系统解决方案。Whale Docs 是它的统一文档门户，覆盖产品本身、柜台操作、实施流程与三种 API 接入方式。

## 产品

<CardGroup cols={2}>
  <Card title="WhaleSDK" icon="smartphone" href="/cn/whalesdk/overview">
    将完整交易体验嵌入自有客户端 —— 提供 iOS、Android 与 WebTrade 三种形态的可直接集成 UI。
  </Card>
  <Card title="Broker API" icon="server" href="/cn/broker-api/overview">
    面向券商后端的机构级 Server-to-Server API。以券商机构为授权边界，覆盖机构数据与 SaaS 柜台能力。
  </Card>
  <Card title="Trading API" icon="chart-candlestick" href="/cn/trading-api/introduction">
    供券商自研客户端接入的客户级 API，以单个客户身份授权。计划 2026 年第四季度启动建设。
  </Card>
  <Card title="OpenAPI" icon="plug" href="https://open.longportapp.com">
    供券商的开发者客户及 AI 应用使用的客户级开放 API，以单个客户身份授权。
  </Card>
</CardGroup>

## 按角色进入

| 你是 | 首要任务 | 入口 |
| --- | --- | --- |
| 券商决策者 / 产品负责人 | 理解 Whale 能力、实施范围和上线过程 | 本栏目（Docs） |
| 券商实施团队 | 理解业务流程、准备资料、完成验收 | 本栏目（Docs） |
| 券商 App 开发团队 | 将完整交易 UI 嵌入自有 App 或 Web 容器 | [WhaleSDK](/cn/whalesdk/overview) |
| 券商后端开发者 | 以机构身份集成 SaaS 柜台能力 | [Broker API](/cn/broker-api/overview) |
| 券商客户端开发者 | 为单个客户构建交易客户端 | [Trading API](/cn/trading-api/introduction) |
| 开发者客户 / AI 开发者 | 以自己的客户身份构建应用 | [OpenAPI ↗](https://open.longportapp.com) |
