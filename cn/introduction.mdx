Whale API 为 SaaS 租户提供以编程方式接入 Longport Whale 证券交易平台的能力。本参考文档当前覆盖资产域接口，后续将持续扩充。

## 接口地址（Base URL）

| 环境 | 域名 |
| --- | --- |
| 生产 | `https://b-api.lbkrs.com` |
| 测试 | `https://b-api.longbridge.xyz` |

接口按业务域分组（资产 / 款项管理 / 风控 / …）。`data_porter/<template_id>/info` 是一个多用途查询接口：单一物理端点，不同 `template_id` 承载不同业务数据集。

## 开始之前

1. 获取租户凭证（`APP_KEY`、`ACCESS_TOKEN`、`SECRET`），由 Longport Whale 按租户签发。
2. 阅读[鉴权签名](/cn/essentials/authentication)，了解请求签名机制。
3. 查看[透传请求头](/cn/essentials/passthrough-headers)，了解语言与平台相关的请求头。

<Note>
官方 SDK 已内置请求签名逻辑。仅在直接调用 HTTP API 时才需要自行实现签名。
</Note>
