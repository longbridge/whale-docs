Whale API 为 SaaS 租户提供以编程方式接入 Longbridge Whale 证券交易平台的能力，覆盖账户、资产、交易、新股认购（IPO）、出入金及股票转仓等核心业务。

## 接口地址（Base URL）

```text
https://openapi.longbridge.com
```

所有接口均位于 `/v1/whaleapi` 路径前缀下（少数接口使用 `/v2` 或 `/v3`）。

## 开始之前

1. 获取租户凭证（`APP_KEY`、`ACCESS_TOKEN`、`SECRET`）—— Access Key 的管理接口参见 OpenAPI 分组。
2. 阅读[鉴权签名](/cn/essentials/authentication)，了解请求签名机制。
3. 查看[透传请求头](/cn/essentials/passthrough-headers)，了解语言与平台相关的请求头。

<Note>
官方 SDK 已内置请求签名逻辑。仅在直接调用 HTTP API 时才需要自行实现签名。
</Note>
